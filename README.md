# 나라장터 채권평가회사 공고 수집기

채권평가회사(업종코드 3865)가 맡을 수 있는 입찰공고를 매일 자동으로 찾아
**엑셀에 기록**하고 **메일로 공지**합니다. 엑셀에 오른 건은
**공고문 PDF 도 한 개씩** 받아둡니다.

**파이썬을 설치할 필요가 없습니다.** 받은 폴더 안에 다 들어 있습니다.

## 1. 받은 폴더

`나라장터 수집기` 폴더를 통째로 받았을 것입니다.
**아무 데나 두어도 됩니다.** 바탕화면이든 `C:\나라장터 수집기` 든 상관없습니다.
다만 한번 정하면 옮기지 마세요([2-7](#2-7-다른-pc로-옮길-때)).

```
나라장터 수집기\
├─ 나라장터수집기.exe    ← 더블클릭하면 설정 화면이 브라우저에 열립니다
├─ 실행.bat              ← 자동 실행이 쓰는 파일. 열어볼 일 없습니다
├─ 설명서.pdf            ← 이 문서
└─ _internal\            ← 파이썬과 패키지. 절대 지우지 마세요
```

**평소에 여는 것은 `나라장터수집기.exe` 하나뿐입니다.** 설정을 고치는 것도,
손으로 한 번 돌려보는 것도 전부 이 화면에서 합니다. 매일 도는 자동 수집은
`실행.bat` 이 맡고, 그건 작업 스케줄러가 알아서 부릅니다.

**`_internal` 폴더는 건드리지 마세요.** 파이썬 본체와 패키지가 들어 있습니다.
지우거나 옮기면 exe 가 **검은 창만 깜빡이고 그대로 꺼집니다.**

### 처음 실행하면 옆에 생기는 것

```
├─ config.yaml           ← 인증키·기간·저장위치·메일 설정
├─ 점수표.yaml           ← 공고명 판정 키워드
├─ 수집결과\             ← 엑셀과 공고문 PDF
├─ 로그\                 ← 실행 기록
└─ 백업\                 ← 편집기가 저장 전에 떠두는 원본
```

설정은 전부 `_internal` **바깥**, exe 와 같은 자리에 있습니다.
그래서 프로그램을 새 버전으로 바꿔도 고쳐 둔 설정이 남습니다
([2-6](#2-6-새-버전으로-바꿀-때)).

무엇이 어떻게 쌓이는지는 [2-5](#2-5-만들어지는-것) 에 있습니다.

## 2. 설치

**2-1 부터 2-4 까지 순서대로** 하면 됩니다.
다 하면 평일 오전 10시·오후 4시에 알아서 돌고, 결과가 엑셀에 쌓이고
메일이 나갑니다.

| | 단계 | 하는 일 |
|---|---|---|
| **준비** | [2-1](#2-1-인증키-발급) 인증키 발급 | data.go.kr 가입 |
| **설정** | [2-2](#2-2-설정-채우기) 설정 채우기 | exe 더블클릭 |
| | [2-3](#2-3-시험-삼아-한-번-돌려보기) 시험 실행 | 잘 도는지 확인 |
| **자동화** | [2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러) 작업 스케줄러 등록 | 명령 두 줄 |

**명령 프롬프트는 [2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러) 에서 딱 한 번 씁니다.**
나머지는 전부 exe 를 더블클릭해서 화면으로 합니다.
명령으로 직접 돌리는 방법은 따로 [부록 A](#부록-a-명령으로-실행하기-선택) 에 있습니다.

### 2-1. 인증키 발급

1. https://www.data.go.kr 가입 후 로그인
2. **조달청_나라장터 입찰공고정보서비스** 검색 → 활용신청 (자동승인)
3. 마이페이지 > 데이터활용
4. '개인 API 인증키' 항목에서 인증키 복사(**Decoding**)

**인증키는 쓰는 PC마다 따로 발급받으세요.** 일일 호출 한도가 키 단위로
걸리기 때문에, 같은 키를 두 사람이 쓰면 한쪽이 한도를 다 쓴 날 다른 쪽도
같이 멈춥니다. 발급은 자동승인이라 몇 분이면 끝납니다.

### 2-2. 설정 채우기

**`나라장터수집기.exe` 를 더블클릭합니다.** 검은 창이 하나 뜨고, 잠시 뒤
브라우저가 저절로 열립니다. 이 화면에서 설정을 채우면 오타로 파일이 깨질
일이 없습니다.

> 검은 창은 **닫지 마세요.** 그 창이 편집기입니다. 다 쓰고 나면 검은 창에서
> Ctrl+C 를 누르거나 창을 닫으면 편집기가 꺼집니다.
> 브라우저가 안 열리면 검은 창의 메시지를 보세요([5. 안 될 때](#5-안-될-때)).

아래 세 가지를 채우고 맨 위 **저장**을 누릅니다. 앞의 두 개는 **기본** 탭,
받는 사람은 **메일** 탭에 있습니다.

| 어느 탭 | 편집기에서 | 무엇을 넣나 |
|---|---|---|
| 기본 | **data.go.kr 인증키** | [2-1](#2-1-인증키-발급) 에서 복사한 키를 붙여넣습니다 |
| 기본 | **결과 저장 폴더** | 기본값 `./수집결과` 그대로 두면 됩니다 |
| 메일 | **받는 사람** | 공지 메일을 받을 주소. **처음에는 본인 주소 하나만** 넣으세요 |

나머지 항목은 전부 기본값 그대로 두면 됩니다. 조회 기간·대상 기관·메일 문구
같은 것은 나중에 [3. 설정할 수 있는 것들](#3-설정할-수-있는-것들) 을 보고
고치면 됩니다. 편집기로 할 수 있는 다른 일들은
[3-0](#3-0-편집기로-고치기-권장) 에 정리돼 있습니다.

편집기를 쓰지 않고 메모장으로 직접 고치는 방법은
[3-9](#3-9-yaml-을-직접-고쳐야-할-때) 에 있습니다.

### 2-3. 시험 삼아 한 번 돌려보기

설정이 맞는지 여기서 확인합니다. 편집기 화면 위쪽의 **수동 실행** 탭에서 합니다.

1. **수동 실행** 탭을 누릅니다
2. 조회 범위에서 **`최근 [ 3 ] 일`** 을 고릅니다
3. 옵션의 **`메일 보내지 않음`** 이 켜져 있는지 확인합니다 (기본으로 켜져 있습니다)
4. **실행** 버튼을 누릅니다. 진행 기록이 화면에 그대로 나옵니다
5. 끝나면 `수집결과` 폴더에 `공고목록.xlsx` 가 생겼는지 열어봅니다

**처음부터 기간을 길게 잡지 마세요.** 4개월치는 면허제한 조회만 300회가 넘어
오래 걸리고 중간에 끊기기 쉽습니다. 3~7일로 시작하면 몇 분이면 끝납니다.

실행 버튼 위에는 **실제로 돌아갈 명령줄이 그대로** 나오고, 메일이 진짜
나가는 실행이면 **받는 사람까지 빨간 줄로** 미리 알려줍니다. 시험 삼아
돌렸다가 팀 전체에 메일이 나가는 일이 없습니다.

**메일까지 시험해 보려면** 아웃룩에 초안만 띄워놓고 확인하는 방법이 있습니다.
[3-1](#3-1-메일-켜기끄기-메일만-보내기) 아래쪽의 3단계를 따라 하세요.

`0건`이 나와도 정상일 수 있습니다. 3일 안에 해당하는 공고가 없으면 그렇습니다.
공고는 많은데 계속 0건이면 [5. 안 될 때](#5-안-될-때) 를 보세요.

> **⚠ 이 시험 실행을 꼭 한 번 하고 넘어가세요.**
> 수집기는 `수집결과\_수집이력.json` 을 보고 이미 보낸 공고를 걸러냅니다.
> 새 폴더에는 이 파일이 없어서, **맨 처음 도는 회차는 조회 기간치(기본 7일)가
> 전부 '신규' 로** 메일에 실립니다. 지난주에 이미 받아 본 공고가 한꺼번에
> 다시 오는 셈입니다.
>
> 메일을 끈 채로 여기서 한 번 돌리면 이력 파일이 만들어지므로,
> 그다음 [2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러) 의 정규 발송부터는
> 진짜 신규만 나갑니다. 조회 범위는 맨 위 **`설정된 조회 기간 그대로`** 를
> 고르면 됩니다.

### 2-4. 윈도우 자동 실행 설정 (작업 스케줄러)

**운영 일정: 평일 오전 10시 / 오후 4시, 주말 없음.**

```
나라장터 공고수집 오전    월~금 10:00
나라장터 공고수집 오후    월~금 16:00
```

**명령 프롬프트를 관리자 권한으로 열고** 두 줄이면 됩니다.
`C:\...\실행.bat` 은 받은 폴더의 실제 경로로 바꾸세요.

```
schtasks /create /tn "나라장터 공고수집 오전" /tr "C:\...\실행.bat auto" /sc weekly /d MON,TUE,WED,THU,FRI /st 10:00 /f
schtasks /create /tn "나라장터 공고수집 오후" /tr "C:\...\실행.bat auto" /sc weekly /d MON,TUE,WED,THU,FRI /st 16:00 /f
```

**등록하는 것은 `실행.bat` 입니다.** exe 가 아닙니다. 그 배치가 안에서
exe 를 부르면서 오류 기록과 종료 코드를 챙깁니다([부록 B](#부록-b-실행bat-안쪽)).

**경로 뒤의 `auto` 를 빼지 마세요.** 이 인자가 없으면 오류가 났을 때 배치가
`pause` 에서 멈춰, 아무도 키를 누르지 않는 동안 작업이 "실행 중" 으로 남고
다음 회차가 시작되지 않습니다.

화면에서 만들려면 **작업 스케줄러 → 작업 만들기 → 트리거(매주, 월~금, 10:00)
→ 동작(프로그램 시작 → `실행.bat` 선택, 인수 추가에 `auto`)** 순서입니다.

등록한 뒤 **작업 설정에서 확인할 것**

- **"사용자가 로그온할 때만 실행"** — **발송 방식**이 `outlook` 이면 필수입니다.
  로그온 세션이 없으면 아웃룩을 띄울 수 없어 메일만 실패합니다
  (수집과 엑셀 기록은 정상입니다). `schtasks` 로 만들면 기본이 이 설정입니다
- **"가장 빠른 시간에 누락된 작업 시작"** — PC가 꺼져 있어 건너뛴 실행을
  다음 부팅 때 돌립니다. 조회 기간이 168시간(7일)이면 늦게 돌아도 놓치는
  공고가 없습니다
- **노트북이면 배터리 설정** — 기본값이 "배터리로 실행 중이면 시작 안 함"
  입니다. 배터리에서도 돌게 하려면 꺼두세요

> **⚠ 아웃룩으로 보낼 거면 실행 시각에 아웃룩이 켜져 있어야 합니다.**
> **발송 방식**이 `outlook` 이면 수집기가 이 PC의 아웃룩을 붙잡아 메일을
> 보냅니다. 오전 10시·오후 4시에 아웃룩이 꺼져 있으면
> `아웃룩 발송 —` 오류가 나고 **메일만 실패합니다**(수집·엑셀·PDF 는 정상).
> 출근하면 아웃룩을 열어두는 것이 가장 확실합니다.
> 아웃룩을 늘 켜둘 수 없으면 **발송 방식**을 `smtp` 로 바꾸세요
> ([3-3](#3-3-발송-방식-아웃룩--smtp)).

**주말 제외는 스케줄러가 합니다.** 프로그램에는 요일 개념이 없습니다.
쉬는 날을 바꾸려면 작업 스케줄러에서 트리거의 요일만 고치면 됩니다.

**이 일정에서는 조회 기간을 넓게 잡아야 합니다.** 기본 탭의
**조회 기간 (시간)** 을 `12` 로 두면 전날 16시~22시 6시간이 어느 실행에도
안 들어갑니다. 주말에는 금요일 16시부터 월요일 10시까지 **66시간**이 비고,
공휴일이 끼면 90시간이 넘습니다.
그래서 `168`(7일)로 두고 매번 일주일치를 훑습니다.
겹치는 건 `_수집이력.json` 이 걸러내므로 메일에는 새 공고만 나옵니다.

**여기까지 하면 설치가 끝났습니다.** 다음 실행 시각이 되면 알아서 돌아갑니다.
잘 돌았는지는 `로그\실행.log` 와 결과 폴더로 확인합니다([2-5](#2-5-만들어지는-것)).

### 2-5. 만들어지는 것

```
수집결과/
├── 공고목록.xlsx          ← A·B·C 전부 한 파일 (C는 회색 줄)
├── 공고문/
│   ├── 국민연금공단_국내 대체투자자산(부동산) 공정가치평가_R26BK00123456.pdf
│   └── 사립학교교직원연금공단_대체투자자산 공정가치평가 및 사후모니터링 용역_....pdf
├── _수집이력.json         ← 중복 방지용. 지우지 마세요
└── _면허제한_*.json       ← 면허제한 조회 캐시. 14일 구간마다 한 개
```

엑셀은 실행할 때마다 **아래에 줄이 추가**됩니다. 덮어쓰지 않습니다.

**실행 기록은 `로그/` 에 쌓입니다.**

```
로그/
├── 실행.log              ← 화면에 나온 내용 그대로. 실행할 때마다 누적
├── 실행.log.1            ← 실행.log 가 2MB 를 넘으면 여기로 밀려남
└── 오류.log              ← 프로그램이 아예 못 뜬 경우. 정상이면 0바이트
```

`로그/` 는 **결과 저장 폴더** 안이 아니라 **exe 가 놓인 폴더 옆**에 생깁니다.
저장 위치를 공유폴더로 잡아둔 상태에서 네트워크가 끊기면 그 사실을 기록할
곳까지 같이 사라지기 때문입니다.

- 어떻게 실행했든(더블클릭·명령어·작업 스케줄러) 항상 남습니다.
  실행마다 `==== 실행 2026-08-14 16:00:03  (옵션 없음) ====` 헤더가 붙고,
  붙인 옵션이 그대로 적히므로 **어느 회차가 무슨 조건으로 돌았는지** 알 수 있습니다
- **자동 실행이 의심되면 여기부터 보세요.** 그 시각 헤더가 아예 없으면
  프로그램이 시작조차 못 한 것이므로 `오류.log` 를 확인하면 됩니다
- 지워도 됩니다. 다음 실행 때 다시 만들어집니다

**면허제한 조회는 이어받습니다.** 기간을 길게 잡으면(4개월이면 300회가 넘습니다)
중간에 끊기기 쉬운데, 14일 구간을 하나 받을 때마다 캐시에 남깁니다.
끊겨서 `[경고] 조회가 중간에 끊겨…` 가 뜨면 **같은 조건으로 다시 실행**하세요.
받아둔 구간은 건너뛰고 못 받은 구간부터 이어갑니다.
아직 안 끝난 마지막 구간은 캐시하지 않으므로, 매일 실행에서 오늘 올라온 공고를
놓치는 일은 없습니다.

### 2-6. 새 버전으로 바꿀 때

새 `나라장터 수집기` 폴더를 받았다면, **`나라장터수집기.exe` 와 `_internal`
폴더만 덮어쓰면 됩니다.**

`config.yaml` · `점수표.yaml` 은 **이미 있으면 덮어쓰지 않습니다.**
고쳐 둔 인증키·받는 사람·키워드가 그대로 남습니다.

`수집결과` · `로그` · `백업` 도 건드리지 마세요. 그대로 두면 엑셀과
수집 이력이 이어집니다.

작업 스케줄러도 그대로 둡니다. 등록된 것은 `실행.bat` 의 경로뿐이고
파일 이름이 바뀌지 않기 때문입니다.

### 2-7. 다른 PC로 옮길 때

**폴더를 통째로 복사하면 됩니다.** 파이썬을 깔 필요도, 파일 안을 고칠
필요도 없습니다. 다만 아래 세 가지는 폴더를 옮긴다고 따라오지 않습니다.

1. **인증키** — [2-1](#2-1-인증키-발급). 키는 PC마다 따로 받으세요
2. **작업 스케줄러 등록** — [2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러).
   `/tr` 에 절대경로가 박혀 있어 경로가 바뀌면 다시 만들어야 합니다.
   **같은 PC 안에서 폴더만 옮길 때도 마찬가지입니다**
3. 편집기를 열어 메일 탭의 **받는 사람**과 기본 탭의 **결과 저장 폴더** 확인

**담당자를 교체하는 것이라면 `수집결과` 폴더도 같이 넘기세요.**
`_수집이력.json` 이 없으면 이미 보냈던 공고를 새 PC가 처음 보는 것으로 여겨,
첫 실행 때 조회 기간치가 전부 '신규' 로 한 번에 메일에 실립니다
([2-3](#2-3-시험-삼아-한-번-돌려보기) 의 경고와 같은 이야기입니다).
결과 폴더를 통째로 옮기면 엑셀도 이어서 쌓입니다.

**두 PC에서 동시에 자동 실행하지 마세요.** 각자 폴더를 쓰면 같은 공고 메일이
두 번 가고, 같은 공유폴더를 쓰면 엑셀과 이력이 깨집니다
([3-7](#3-7-저장-위치-네트워크-공유폴더) 참고).

## 3. 설정할 수 있는 것들

설정은 전부 **`나라장터수집기.exe` 를 더블클릭해서 화면으로 고칩니다.**
아래 3-1 부터 3-8 까지는 **편집기 화면 기준**으로 씁니다. 어느 탭의 어느
항목인지만 찾으면 됩니다.

고친 값이 실제로 저장되는 곳은 exe 옆의 `config.yaml` 과 `점수표.yaml` 이지만,
평소에는 이 파일들을 열어볼 일이 없습니다. 편집기가 안 열리거나 저장이 안 될
때만 메모장으로 직접 고칩니다([3-9](#3-9-yaml-을-직접-고쳐야-할-때) 참고).

| 무엇을 고치나 | 탭 | 항목 |
|---|---|---|
| 인증키 | 기본 | **data.go.kr 인증키** |
| 조회 기간 | 기본 | **조회 기간 (시간)** |
| 저장 폴더 | 기본 | **결과 저장 폴더** |
| 받는 사람, 발송 방식 | 메일 | **받는 사람** · **발송 방식** |
| 메일 제목·본문 문구 | 메일 | **메일 문구** 묶음 |
| 조회 업무구분 (용역/물품/공사) | 키워드 > 조회 대상 | **업무구분** |
| 대상 기관 | 키워드 > 대상 기관 | **기관 목록 (가점)** |
| 공고명 키워드·점수 | 키워드 > 점수표 | 묶음 전체 |

### 3-0. 편집기로 고치기 (권장)

`나라장터수집기.exe` 를 더블클릭하면 브라우저가 열리고, 설정을 화면에서
고칠 수 있습니다. 들여쓰기나 따옴표를 직접 맞출 필요가 없습니다.
아래 [3-1](#3-1-메일-켜기끄기-메일만-보내기)~[3-8](#3-8-오전오후-두-번-보내기)
은 전부 이 화면을 두고 하는 이야기입니다.

화면 위쪽 탭은 **파일이 아니라 하는 일**로 나뉘어 있습니다. 어느 탭이 어느
파일을 고치는지는 신경 쓰지 않아도 됩니다.

| 탭 | 여기서 고치는 것 |
|---|---|
| **기본** | 인증키, 조회 기간, 결과 저장 폴더 |
| **메일** | 받는 사람·발송 방식, 메일 문구, SMTP |
| **키워드** | 하위 메뉴 셋 — `조회 대상` (업무구분·업종코드) · `대상 기관` · `점수표` |
| **수동 실행** | 수집기를 화면에서 돌리기, 마지막 회차 메일만 다시 보내기 |

**키워드 탭의 낱말 조각은 색으로 구분됩니다.** 목록 이름을 외우지 않아도
색만 보면 됩니다.

| 색 | 뜻 | 어느 목록 |
|---|---|---|
| 파랑 | 점수를 올린다 | `core` `market` `target` `action` `pdf_strong`, 업종코드 |
| 빨강 | 점수를 깎거나 제외한다 | `kill_hard` `kill_soft` `selectee` |
| 주황 | 거부권을 푼다 | `delegate` |
| 초록 | 기관 이름 | **기관 목록 (가점)** · **검토 문턱을 낮출 기관** · `inst_extra` |

주소는 `127.0.0.1` 이라 이 PC 안에서만 열립니다. 창을 닫으려면 검은 창에서
Ctrl+C 를 누르세요.

**메모장으로 고치는 것보다 나은 점**

- **저장하기 전에 점수를 볼 수 있습니다.** 키워드 탭 아래에 공고명과 기관명을
  넣으면 `수집 / 검토 / 제외` 와 점수·근거가 바로 나옵니다. 문턱을 13에서
  15로 올려보고 판정이 어떻게 달라지는지 저장 없이 확인할 수 있습니다
- 키워드는 낱말 하나가 조각(칩)으로 보이고, `×` 로 지우고 입력칸에 쉼표로
  여러 개를 한 번에 넣을 수 있습니다. 아직 저장하지 않은 것은 점선 테두리로
  표시됩니다
- **중복 검사** — 같은 낱말이 여러 목록에 들어 있는지 보여줍니다.
  일부러 그런 것도 있습니다(`공정가치` 는 `core` 와 `action` 양쪽에 필요)
- **검증 실행** — 점수표가 아직 맞는지 40개 항목으로 검사합니다.
  점수표를 고친 뒤 이걸 꼭 눌러보세요([3-4](#3-4-키워드점수표-고치기))
- **되돌리기** — 가장 최근 백업으로 파일을 되돌립니다. 두 파일 중 어느 쪽을
  되돌릴지 눌러서 고릅니다
- **메일 미리보기** — 저장하기 전에 메일 한 통을 통째로 그려서 보여줍니다
  ([3-2](#3-2-메일-문구-고치기) 참고)
- **수동 실행 탭** — 조회 기간과 옵션을 골라 수집기를 화면에서 돌립니다.
  명령을 칠 필요가 없습니다([2-3](#2-3-시험-삼아-한-번-돌려보기) 참고.
  같은 일을 명령으로 하려면 [부록 A](#부록-a-명령으로-실행하기-선택))

**안전장치**

- **주석이 지워지지 않습니다.** 두 파일은 절반이 주석(설명)입니다. YAML 을
  통째로 다시 쓰면 그게 전부 날아가므로, 편집기는 **고칠 줄만 찾아 그 줄만**
  바꿉니다. 목록 안의 `# --- 기준가격 계열 ---` 같은 구분 주석도 그대로 남습니다
- **쓰기 전에 다시 읽어 확인합니다.** 고친 결과를 YAML 로 다시 파싱해서
  의도한 값과 같은지 대조하고, 다르면 **아예 쓰지 않습니다.** 파일이 반쯤
  망가진 상태로 남는 일이 없습니다
- **저장할 때마다 원본을 `백업/` 폴더에 시각별로 떠둡니다**
- **인증키는 화면에 그대로 보입니다.** 지금 들어 있는 키가 맞는지 눈으로
  확인할 수 있어야 해서입니다. 요금이 붙지 않는 무료 API 이고, 어차피
  `config.yaml` 에 평문으로 들어 있고 이 화면은 이 PC 에서만 열립니다.
  화면을 공유하거나 캡처할 때만 조심하면 됩니다
- SMTP 비밀번호는 사내 메일 계정이라 `••••••••` 로 가려집니다. 그대로 두면
  건드리지 않고, 고치려면 그 칸을 지우고 새로 넣으세요
- 줄바꿈도 파일별로 유지합니다 (`config.yaml` 은 LF, `점수표.yaml` 은 CRLF)

**인증키 칸을 비운 채로 저장하면 키가 지워집니다.** 그 상태로 수집기를 돌리면
`config.yaml 의 service_key 가 비어 있습니다` 로 멈춥니다. 되돌리기 버튼이나
`백업/` 폴더에서 복구하면 됩니다.

**주의**

- 편집기를 열어둔 채로 메모장에서 같은 파일을 고치면 나중에 저장한 쪽이
  이깁니다. 한쪽만 쓰세요
- 검증 실행과 수동 실행 탭은 **저장된 파일**을 읽습니다. 그래서 고친 내용이
  남아 있으면 먼저 저장하라고 알려줍니다
- 수동 실행 탭에서 돌린 수집기는 **편집기 창(검은 창)을 닫으면 같이 멈춥니다.**
  자동 수집은 편집기와 상관없이 작업 스케줄러가 `실행.bat` 으로 돌립니다
  ([2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러))

### 3-1. 메일 켜기·끄기, 메일만 보내기

**메일 탭**의 맨 위 **메일** 묶음에 다 있습니다. 켜고 끄는 항목은 체크를
넣으면 `켜짐`, 빼면 `꺼짐` 으로 바뀝니다.

| 항목 | 기본 | 하는 일 |
|---|---|---|
| **메일 발송** | 켜짐 | 끄면 수집·엑셀·PDF 만 하고 메일을 보내지 않습니다 |
| **발송 방식** | `outlook` | `outlook` / `smtp` 중에서 고릅니다 ([3-3](#3-3-발송-방식-아웃룩--smtp)) |
| **받는 사람** | — | 공지 메일을 받을 주소. 테스트 단계에는 한 명만 |
| **참조** | 비어 있음 | 참조로 넣을 주소 |
| **오류 메일 받는 사람** | 비어 있음 | 조회가 실패한 회차에만 갑니다. 비워두면 위 '받는 사람' 으로 갑니다 |
| **보내지 않고 초안만 띄우기** | 꺼짐 | 켜면 발송하지 않고 아웃룩에 초안만 띄웁니다 |
| **공고목록.xlsx 첨부** | 켜짐 | 엑셀을 붙입니다 |
| **공고문 PDF 첨부** | 켜짐 | 표에 오른 공고의 공고문을 붙입니다 |
| **첨부 총 용량 상한 (MB)** | 15 | 넘으면 그 지점부터 붙이지 않습니다 |
| **신규 0건일 때도 보내기** | 켜짐 | '특이사항 없음' 한 줄을 보냅니다 |

**받는 사람**과 **참조**는 낱말 조각(칩)입니다. 주소를 넣고 Enter, 지울 때는
`×` 를 누릅니다. 쉼표로 여러 개를 한 번에 넣을 수도 있습니다.

수집이 끝나면 **그 회차에 새로 잡힌 공고**와 **이미 알린 공고 중 바뀐 것**이
메일로 나갑니다. 바뀐 것이 있으면 표가 두 개가 되고, **변경·취소 표가 위**에
옵니다. 마감이 미뤄지거나 취소된 건은 이미 검토를 시작한 공고라 새 공고보다
급하기 때문입니다.

```
■ 이미 알려드린 공고 중 바뀐 것 2건
   구분 · 공고종류 · 수요기관 · 공고명 · 변경내역 · 마감일시

■ 새로 올라온 공고 3건
   구분 · 정확도 · 공고종류 · 등록일 · 수요기관 · 공고명 · 마감일시 · 사업예산 · 검색 키워드
```

바뀐 것이 없으면 아래 표 하나만 나갑니다(`■` 제목도 안 붙습니다).
공고명을 누르면 나라장터 공고 화면이 열립니다.

- **구분** — 그 메일 안에서의 순번(1, 2, 3…)입니다. 엑셀에는 없습니다.
  엑셀은 실행할 때마다 아래로 쌓이는 파일이라 회차마다 번호가 겹칩니다
- **공고종류** — `변경`·`취소` 는 빨강, `재공고` 는 주황으로 표시됩니다.
  대부분은 `신규` 라 눈에 띄어야 할 것만 색을 줬습니다
- **변경내역** — 변경·취소 표에만 있습니다. 무엇이 어떻게 바뀌었는지
  (`마감 08-26 → 09-02`) 그대로 보여줍니다. 취소된 줄은 분홍 바탕입니다
- **제목** — 변경·취소가 섞이면 `신규 5건` 이라고 할 수 없으므로
  `공고 5건 (수집 2건 · 검토 1건 · 변경 1건 · 취소 1건)` 으로 나갑니다
  (**제목 (변경·취소가 섞였을 때)** 문구)
- **사업예산** — 배정예산(부가세 포함)입니다. 추정가격은 엑셀에만 있습니다.
  공고에 금액이 안 적혀 있으면 `-` 입니다
- **검색 키워드** — 무엇에 걸려서 올라왔는지만 짧게 보여줍니다.
  A 는 `업종코드 3865` / `채권평가회사`, B·C 는 공고명에서 걸린 낱말
  (`공정가치평가, 대체투자자산`). 점수 계산 내역(`조합+4`)은 넣지 않습니다.
  `공정가치평가` 가 걸리면 `공정가치` `평가` 는 겹치므로 긴 것만 남깁니다

**수집 없이 메일만 다시 보내기**

편집기의 **수동 실행** 탭에서 **`마지막 회차 메일만 보내기`** 버튼을 누르면 됩니다.

`공고목록.xlsx` 에서 **마지막 회차**를 읽어 그 내용으로 메일만 보냅니다.
API 를 호출하지 않으므로 호출 한도를 쓰지 않고, 몇 초면 끝납니다.
메일이 실패해서 다시 보낼 때도 이걸 씁니다.
**메일 발송**이 꺼져 있어도 보냅니다(보내려고 누른 것이므로).

처음 설정할 때는 아래 순서를 권합니다.

1. 메일 탭에서 **받는 사람**을 본인 주소 하나만 남기고,
   **보내지 않고 초안만 띄우기**를 켠 뒤 맨 위 **저장**
2. 수동 실행 탭에서 **`마지막 회차 메일만 보내기`** → **아웃룩에 초안이 뜹니다.** 내용 확인
3. 문제 없으면 **보내지 않고 초안만 띄우기**를 끄고 저장한 뒤 다시 누르면 실제로 발송

**첨부**

**공고문 PDF 첨부**가 켜져 있으면 표에 오른 공고의 공고문을 `공고문/` 폴더에서
찾아 붙입니다. **이번에 새로 받은 것만이 아니라** 표에 오른 건이면 전부 붙으므로,
메일만 다시 보낼 때도 첨부가 빠지지 않습니다.
합계가 **첨부 총 용량 상한 (MB)** 을 넘으면 넘는 지점부터 붙이지 않고 화면에
알려줍니다(본문 표는 그대로이므로 내용 확인은 됩니다).

**신규 0건일 때**

**신규 0건일 때도 보내기**가 켜져 있으면 이 한 줄만 나갑니다. 표도 첨부도 없습니다.

```
제목  [나라장터] 08.13(오전) 입찰 공고 특이사항 없습니다
본문  08.13(오전) 나라장터 입찰 공고 특이사항 없습니다.
```

끄면 아무것도 보내지 않습니다. 다만 그러면 받는 쪽에서
**"공고가 없었다" 와 "수집기가 죽었다" 를 구분할 수 없습니다.**
켜두는 편이 안전합니다.

단, **조회가 실패한 회차는 이 설정과 상관없이 메일이 나갑니다.** 끄면
안 나가는 것은 '진짜로 0건인 회차' 뿐입니다 (4-7 참고).

### 3-2. 메일 문구 고치기

**메일 탭**의 **메일 문구** 묶음에 다 있습니다. 묶음 맨 아래
**메일 미리보기** 버튼을 누르면 저장하기 전에 메일 한 통이 통째로 나옵니다.

- 실제로 보낼 때 쓰는 코드가 그대로 그립니다. 미리보기와 실제 메일이
  달라지지 않습니다
- **위쪽 단추 네 개를 눌러 네 경우를 다 보세요.** 갈래마다 나가는 문구가
  통째로 다릅니다
  - `공고 3건` — 평소 메일
  - `신규 0건` — **제목 (0건일 때)** 와 **0건일 때 본문**만 나갑니다.
    실무에서 가장 자주 나가는 것이 이쪽입니다
  - `변경·취소 포함` — 위에 변경표가 하나 더 붙은 모습입니다.
    마감이 미뤄진 건과 취소된 건이 한 줄씩 들어 있습니다
  - `일부 조회 실패` — 제목 끝에 `— 일부 조회 실패`, 본문 맨 위에 빨간
    경고 상자가 붙습니다
  - `자동수집 실패` — 결과 메일 대신 나가는 **오류 메일**입니다.
    받는 사람이 다릅니다(**오류 메일 받는 사람**). 화면에 누구에게 가는지
    같이 보여줍니다
  뒤의 두 갈래는 사고가 나야 볼 수 있는 메일입니다. 그때 처음 보지 않도록
  여기서 미리 확인해 두세요
- 예시에는 A·B·C 가 하나씩 들어 있어 회색 줄과 **C가 있을 때 덧붙는 안내**
  까지 같이 보입니다
- **자리표시자를 틀리면 타이핑하는 즉시 그 칸 아래에 빨간 글씨로 알려줍니다.**
  아래 표의 '쓸 수 있는 값' 도 칸마다 적혀 있습니다

| 항목 | 어디에 나오는가 | 쓸 수 있는 값 |
|---|---|---|
| **제목 (공고 있을 때)** | 공고가 있을 때 메일 제목 | `{날짜}` `{건수}` `{내역}` |
| **제목 (0건일 때)** | 공고가 0건일 때 제목 | `{날짜}` |
| **본문 첫 줄** | 본문 맨 윗줄 | `{시각}` `{기간}` |
| **표 위 요약** | 표 바로 위 (굵게) | `{건수}` `{내역}` |
| **0건일 때 본문** | 0건일 때 본문 (이 한 줄이 전부) | `{날짜}` |
| **표 아래 안내 (A·B·C 설명)** | 표 아래 회색 글씨 | 없음 |
| **C가 있을 때 덧붙는 안내** | C 가 있을 때만 덧붙음 | 없음 |
| **맨 아래 작은 글씨** | 맨 아래 작은 글씨 | `{폴더}` |

`{중괄호}` 는 보낼 때 값으로 바뀝니다.

```
{날짜}  08.13(오전)
{건수}  13
{내역}  수집 9건 · 검토 4건
{시각}  2026.08.13 09:00
{기간}  조회기간 08.12 21:00 ~ 08.13 09:00
{폴더}  결과가 저장된 경로
```

표 아래 A·B·C 설명은 **표 아래 안내 (A·B·C 설명)** 칸입니다.
지금 들어 있는 내용은 이렇습니다.

```
공고명을 누르면 나라장터 공고 화면이 열립니다.
A = 시가/대체 평가 및 채권평가회사(업종코드) 키워드 일치 · B = 키워드 일부 일치 · C = 기금/공제회 관련, 검토 필요 공고 (회색 줄)
```

고칠 때 알아둘 것:

- **따옴표나 들여쓰기는 신경 쓰지 않아도 됩니다.** 칸에 보이는 그대로가
  메일에 나갑니다. 파일에 쓸 때 감싸야 할 것은 편집기가 알아서 감쌉니다
- **표 아래 안내**와 **C가 있을 때 덧붙는 안내**는 여러 줄 칸입니다.
  Enter 로 줄을 바꾸면 메일에서도 줄바꿈으로 나갑니다
- 칸을 **비워두면 기본 문구**가 쓰입니다
- **없는 이름(예: `{날자}`)을 쓰면 그 줄만 기본 문구로 나갑니다.** 메일 자체가
  안 나가는 일은 없습니다. 다만 **자동 실행 중에는 이 알림이 `로그\실행.log`
  에만 남아** 알아채기 어렵습니다. 그래서 편집기가 타이핑하는 즉시
  그 칸 아래에 빨간 글씨로 잡아줍니다
- 표의 컬럼 이름과 정확도 표시(`A 일치` 등)는 여기서 못 바꿉니다

### 3-3. 발송 방식 (아웃룩 / SMTP)

메일 탭의 **발송 방식**에서 고릅니다.

| | `outlook` | `smtp` |
|---|---|---|
| 필요한 것 | 이 PC에 설치된 아웃룩 | 사내 메일 서버 주소·포트 (IT 문의) |
| 발신자 | 아웃룩에 로그인한 본인 계정 | **발신 주소** 칸에 적은 주소 |
| 막힐 수 있는 경우 | 보안 정책으로 스크립트의 아웃룩 사용 차단 | 릴레이 허용 IP·인증 정책 |

**아웃룩 방식이 준비가 간단합니다.** 서버 정보를 받을 필요가 없습니다.
아웃룩을 다루는 데 필요한 부품은 폴더 안에 이미 들어 있습니다.
다만 **아웃룩이 실행 중이어야** 하고, 작업 스케줄러로 돌릴 때는
"사용자가 로그온할 때만 실행" 으로 둬야 합니다(로그온 세션이 없으면
아웃룩을 띄울 수 없습니다).

로그온 여부와 무관하게 자동 발송해야 하면 **발송 방식**을 `smtp` 로 바꾸고,
IT 부서에서 아래를 받아야 합니다.

- 사내 SMTP 서버 주소와 포트 (릴레이 25 / 인증 587)
- 인증이 필요한지, 필요하면 발송 전용 계정
- 발신 주소로 쓸 수 있는 계정 (예: `나라장터알림@회사.co.kr`)

받은 값은 메일 탭 맨 아래 **SMTP (발송 방식이 smtp 일 때만)** 묶음의
**서버 주소** · **포트** · **TLS** · **계정** · **비밀번호** · **발신 주소**
칸에 넣습니다. 인증이 필요 없으면 계정·비밀번호는 비워둡니다.
비밀번호 칸만 `••••••••` 로 가려집니다([3-0](#3-0-편집기로-고치기-권장)).

### 3-4. 키워드·점수표 고치기

공고명 판정에 쓰는 것은 전부 **키워드 탭 > 점수표**에 있습니다.
배점은 항목 이름 옆에 조각으로 같이 표시됩니다.

**문턱과 배점** 묶음 — 숫자 칸입니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| **수집 문턱** | 이 점수 이상이면 자동 수집 (A·B) | 13 |
| **검토 문턱** | 이 점수 이상이면 검토 필요 (C, 회색 줄) | 7 |
| **연기금·공제회 검토 문턱** | **검토 문턱을 낮출 기관**에만 적용 ([3-5](#3-5-대상-기관-고치기)) | 5 |
| **기관 가점** | **기관 목록 (가점)** 에 걸리면 더하는 점수 | +3 |
| **기관 보강 가점** | **inst_extra** 목록에 걸리면 더하는 점수 | +2 |

**키워드** 묶음들 — 낱말 조각(칩)입니다.

| 항목 | 뜻 | 배점 |
|---|---|---|
| **core — 평가 확정어** | `공정가치평가` `시가평가` … | 8점씩, 최대 3개 |
| **market — 채권시장 제도·연구** | `장외채권` `채권시장` … | 8점 |
| **target — 평가 대상** | `대체투자자산` `기금` `펀드` … | 2점씩, 최대 2개 |
| **action — 평가·산출 행위** | `평가` `검증` `산출` … | 2점씩, 최대 2개 |
| **selectee — 피선정 신호** / **delegate — 대행 신호** | 우리가 '뽑히는 쪽'인 공고를 0점 처리 / 그 예외 | — |
| **kill_hard — 확정 제외** | `환경영향평가` `회계감사` … | -12점씩 |
| **kill_soft — 약한 제외** | `시스템 구축` `유지관리` … | -5점씩 |
| **inst_extra — 기관 보강 목록** | 기관 목록에 없어서 놓치던 기금 운용기관 | 위 보강 가점 |
| **pdf_strong — 공고문에서 찾을 키워드** | 공고문 PDF 본문에서 찾을 낱말 | 걸리면 무조건 수집 (A) |

**target** 과 **action** 이 둘 다 걸리면 +4 가 붙습니다.

**고친 뒤에는 반드시 검증을 돌리세요.** 편집기에서 **검증 실행** 버튼을
누르면 됩니다.

검증용 공고 8건이 여전히 잡히는지, 걸러야 할 것이 걸러지는지 40개 항목을 확인합니다.
키워드 하나 고쳤다가 다른 공고를 놓치는 사고를 막는 장치입니다.
마지막 4개는 공고문에서 자격요건 구간을 제대로 잘라내는지 보는 항목으로,
**pdf_strong** 을 고쳤을 때 같이 확인됩니다.

**놓친 공고가 발견되면** 검증 목록에 그 공고명을 넣어야 합니다.
이 목록은 프로그램 안에 들어 있어 편집기로는 못 고칩니다.
넘겨준 담당자에게 공고명과 기관명을 알려주세요.

개별 공고명만 빠르게 확인하려면 **키워드 탭 아래쪽 칸에 공고명과
기관명을 넣으면** 됩니다. 저장하기 전 상태로 채점하므로, 고친 것이 어떻게
먹히는지 바로 보입니다.

실제 공고에 어떻게 먹히는지 보려면 수동 실행 탭에서 **`최근 30일`** 에
**`PDF 저장 안 함`** · **`메일 보내지 않음`** 을 켜고 한 번 돌려보는 것이
빠릅니다. 엑셀의 **점수·근거** 칸에 왜 그 판정이 나왔는지 그대로 찍힙니다.

### 3-5. 대상 기관 고치기

**키워드 탭 > 대상 기관**의 **기관 목록 (가점)** 에 기관 이름의 **일부만**
적으면 됩니다. `공제회` 한 조각으로 군인공제회·행정공제회·교직원공제회가
모두 걸립니다. 공고기관과 수요기관을 **둘 다** 검사합니다(조달청 대행 공고는
공고기관이 '조달청'이고 실제 발주처가 수요기관에 들어가기 때문입니다).

여기 있으면 버리는 게 아니라 **+3점 가점**입니다. 목록에 없어도 공고명 점수가
높으면 수집됩니다. 그래서 한국벤처투자·전파진흥원처럼 목록에 없던 기금
운용기관 공고도 잡힙니다.

같은 화면의 **검토 문턱을 낮출 기관**에 있는 기관(연기금 4곳 + 공제회)은
검토(C) 문턱이 7점이 아니라 **5점**입니다.
이유는 [4-4](#4-4-연기금공제회-문턱을-낮춘-이유) 를 보세요.

### 3-6. 조회 기간 (시간)

**기본 탭**의 **조회 기간 (시간)** 칸에 시간 단위로 넣습니다. `168` 이 7일입니다.

**넉넉하게 잡는 것이 맞습니다.** 이미 보낸 건은 `_수집이력.json` 이 걸러내므로
겹쳐서 조회해도 메일에는 새 공고만 나옵니다.
평일 2회·주말 휴무 일정이라면 `168` 을 권합니다
([2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러) 참고).

### 3-7. 저장 위치 (네트워크 공유폴더)

결과를 공유폴더에 쌓으면 **다른 사람은 아무것도 설치할 필요가 없습니다.**
**기본 탭**의 **결과 저장 폴더** 칸에 경로를 그대로 넣으면 됩니다.

```
\\파일서버\공유\조달\공고수집
```

**따옴표는 붙이지 마세요.** 칸에 보이는 그대로가 경로가 됩니다.
파일에 쓸 때 감싸야 할 것은 편집기가 알아서 감쌉니다.

**드라이브 문자(Z:)를 쓰면 안 됩니다.** 매핑된 드라이브는 **로그인한 세션에만
존재**합니다. 작업 스케줄러를 "사용자의 로그온 여부에 관계없이 실행"으로 두면
그 드라이브를 못 찾아 매일 조용히 실패합니다. 반드시 `\\서버이름\...` 형태로 쓰세요.

**실행은 한 대에서만.** 여러 PC가 같은 공유폴더에 동시에 쓰면 엑셀과 수집 이력이
깨집니다. 실행 중에는 `_실행중.lock` 이 생기고, 다른 PC에서 실행하면 중단됩니다.
비정상 종료로 남았다면 3시간 뒤 자동으로 무시되고, 급하면 직접 지우면 됩니다.

### 3-8. 오전·오후 두 번 보내기

작업 스케줄러에 **트리거를 두 개** 만들고, 기본 탭의
**조회 기간 (시간)** 을 `12` 로 두면 됩니다.
직전 12시간 안에 올라온 공고만 보므로 같은 공고가 두 번 가지 않습니다
(`_수집이력.json` 이 한 번 더 걸러줍니다).
제목에 `오전` / `오후` 가 자동으로 붙습니다.

```
[나라장터] 08/13 오전 신규 5건 (수집 3건 · 검토 2건)
```

다만 평일 2회·주말 휴무 일정에서는 `12` 가 시간대를 비웁니다.
`168` 을 권하는 이유는 [2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러) 에 있습니다.

### 3-9. YAML 을 직접 고쳐야 할 때

평소에는 편집기만 쓰면 됩니다. 아래 세 경우에만 `config.yaml` ·
`점수표.yaml` 을 메모장으로 직접 엽니다. 두 파일 모두 exe 와 같은 폴더,
`_internal` 바깥에 있습니다.

- 편집기가 **아예 안 열릴 때** (검은 창에 오류가 뜨고 브라우저가 안 열림)
- 편집기가 **저장을 거부할 때** (아래 설명)
- 편집기 화면에 **없는 항목**을 고쳐야 할 때

**편집기가 저장을 거부했다면 파일은 그대로입니다.** 편집기는 고친 내용을
파일에 쓰기 직전에 다시 읽어보고, 의도한 값과 다르면 **아예 쓰지 않습니다.**
그러니 "저장하지 못했습니다" 가 떴을 때 파일이 반쯤 망가졌을 걱정은 없습니다.
그대로 메모장으로 고치면 됩니다.

| 편집기가 이렇게 말하면 | 뜻 |
|---|---|
| `YAML 로 읽히지 않습니다` | 넣은 값에 YAML 이 특별하게 보는 문자가 있습니다. 그 값을 따옴표로 감싸세요 |
| `의도한 값과 다릅니다` | 편집기가 고칠 줄을 잘못 찾았습니다. 그 항목만 메모장에서 고치세요 |
| `…를 찾지 못했습니다` | 그 항목이 `config.yaml` 에 아예 없습니다. 아래 '망가뜨렸으면' 을 보세요 |

**메모장으로 여는 법** — 파일 우클릭 → 연결 프로그램 → 메모장.
**저장할 때 인코딩을 `UTF-8` 로 두세요.** 저장 창 아래쪽에 있습니다.
`ANSI` 로 저장하면 한글이 전부 깨져서 수집기가 읽지 못합니다.

**직접 고칠 때 지킬 것 다섯 가지**

```yaml
hours: 168                  # ① 이름 다음에 콜론, 그 뒤에 공백 한 칸
institutions:
  - 국민연금공단              # ② 목록은 공백 두 칸 + 하이픈 + 공백
  - 공제회
industry_codes:
  - '3865'                  # ③ 숫자처럼 보이는 값은 따옴표로
output_dir: './수집결과'      # ④ 마침표·역슬래시로 시작하는 값도 따옴표로
# 이 줄은 설명입니다          # ⑤ # 뒤는 프로그램이 안 읽습니다
```

1. **`이름: 값`** — 콜론 뒤에 공백이 한 칸 있어야 합니다. `hours:168` 은 안 됩니다
2. **들여쓰기는 공백만.** Tab 키를 쓰면 안 됩니다. 눈으로는 같아 보이는데
   프로그램은 오류를 냅니다. 위아래 줄과 칸 수를 똑같이 맞추세요
3. **`3865` 처럼 숫자만 있는 값은 `'3865'`** 로 감쌉니다. 안 감싸면 숫자로
   읽혀서 업종코드가 안 맞습니다
4. **`:` 나 `#` 가 값 안에 들어가면** 그 값 전체를 따옴표로 감쌉니다
5. 지우고 싶은 줄은 **맨 앞에 `#` 를 붙이면** 지우지 않고 끌 수 있습니다.
   나중에 되살리기 쉽습니다

**고친 뒤 확인** — exe 를 다시 열어보세요. **열리면 문법이 맞은 것**입니다.
편집기는 두 파일을 읽어야 화면을 그리므로, 문법이 틀리면 검은 창에
몇 번째 줄이 문제인지 나옵니다. 점수표를 고쳤다면 이어서 **검증 실행**까지
누르세요.

**망가뜨렸으면 되돌리면 됩니다**

- `백업\` 폴더에 편집기가 저장할 때마다 떠둔 원본이 시각별로 있습니다.
  가장 최근 것을 복사해 이름을 `config.yaml` 로 바꾸면 끝입니다.
  편집기의 **되돌리기** 버튼이 이걸 대신 해줍니다
- 백업까지 손쓸 수 없게 됐으면 **그 파일을 지우고 exe 를 다시 실행하세요.**
  `config.yaml` 과 `점수표.yaml` 은 없으면 기본값이 새로 만들어집니다.
  `config.yaml` 을 새로 만들었다면 인증키와 받는 사람을 다시 넣어야 합니다
  ([2-2](#2-2-설정-채우기))

## 4. 왜 이렇게 만들었는가

### 4-1. 판정 순서

```
[1차] 면허제한 API 에 업종코드 3865       → 무조건 수집             [A]
[2차] 공고명 점수 (키워드 탭 > 점수표)
        13점 이상 → 3차로                 ← 수집 문턱
        7~12점    → 3차로 (검토 필요)     ← 검토 문턱
                    연기금·공제회는 5점부터   ← 연기금·공제회 검토 문턱
        그 미만   → 버림
[3차] 위 후보만 첨부 PDF 를 열어 자격요건 확인
[4차] PDF 에 '채권평가회사' '3865' 등 발견 → 무조건 수집             [A]
[5차] PDF 키워드 없지만 13점 이상          → 수집                   [B]
[6차] PDF 키워드 없고 7~12점               → 검토 필요로 표시        [C]
```

**3차에서 PDF 를 여는 대상을 2차 통과분으로 좁힌 이유**는 호출량입니다.
한 달 공고가 약 3만 건이라 전부 PDF 를 열 수는 없습니다.
공고명 점수로 후보를 줄인 다음에만 PDF 를 봅니다.

### 4-2. 정확도 A · B · C

| | 뜻 | 어떻게 걸렸나 |
|---|---|---|
| **A** | 시가/대체 평가 및 채권평가회사(업종코드) 키워드 일치 | 면허제한에 3865 가 있거나, 공고문 자격요건에 '채권평가회사'·'3865' 가 적혀 있음 |
| **B** | 키워드 일부 일치 | 위 키워드는 없지만 공고명 점수가 13점 이상 |
| **C** | 기금/공제회 관련, 검토 필요 공고 | 공단·공제회 등의 평가성 공고인데 점수가 7~12점이라 애매함 |

**A 는 근거가 두 가지(면허제한 / 공고문)지만 결론이 같아 하나로 묶었습니다.**
어느 쪽으로 걸렸는지는 엑셀의 **근거** 칸에서 볼 수 있습니다.

**C 도 같은 엑셀·같은 메일에 들어갑니다.** 애매한 건을 다른 파일로 빼면
그 파일을 안 열어보게 되기 때문입니다. 엑셀에서는 **회색 줄**, 메일에서는
**C 검토** 로 구분됩니다.

**기관만 맞는 공고는 가져오지 않습니다.** '국민연금공단 3급 승진 역량평가'
처럼 기관은 대상이지만 평가 키워드가 없는 건은 점수 미달로 버려집니다.
C 는 기관과 **평가 관련 키워드가 함께** 걸린 것만 들어옵니다.

### 4-3. 살아있는 공고만 남기는 이유

판정에 앞서 **살아있는 공고만 남깁니다.** 목록 API 는 같은 공고를 차수마다
한 줄씩 주는데, 나라장터 화면은 최신 차수만 보여줍니다. 그대로 두면 한 공고가
엑셀에 여러 줄로 쌓입니다.

- 같은 공고번호는 **차수가 가장 높은 것 하나만** 씁니다
- **취소공고는 그 공고번호를 통째로 버립니다.** 취소 줄만 빼면 이미 없어진
  원공고가 마감일시를 달고 남아 살아있는 것처럼 보입니다.
  공고를 취소하고 몇 분 뒤 **새 번호로 다시 올리는** 기관이 실제로 있습니다
  (국민연금공단 대체투자자산 건이 그랬습니다)

### 4-4. 연기금·공제회 문턱을 낮춘 이유

**검토 문턱을 낮출 기관**에 올려둔 기관(연기금 4곳 + 공제회)은
검토 문턱이 7점이 아니라 **5점**입니다. 이 기관들은 확정어 없이 5~6점에
머무는 공고가 실제로 우리 일인 경우가 있습니다([3-5](#3-5-대상-기관-고치기)).

```
5점  한국지방재정공제회  자산운용 컨설팅 연구용역          → C 로 올라옴
6점  건설근로자공제회    기준 포트폴리오 도입 및 중장기 자산운용전략 개편 연구용역
5점  국민연금공단        ESG 평가데이터 및 ESG 이슈 리서치 제공기관 선정
```

4개월 기준 **13건(월 3건)** 늘어납니다.

**금융공공기관까지 넓히지 마세요.** 같은 4개월에서 13건이 **77건**이 되고,
늘어난 대부분이 뉴스 모니터링·노후장비 교체·감정평가법인 선정처럼 무관한
공고입니다. `기술보증기금 탄소가치평가모델 고도화`(5점)처럼 **걸러야 하는
공고까지 올라옵니다.** 이 5점은 키워드 탭 > 점수표의
**연기금·공제회 검토 문턱** 입니다.

### 4-5. 한 가지 방법만으로는 안 되는 이유

**PDF 키워드만 믿으면 안 됩니다.** 검증용 공고 8건 중 2건
(한국예탁결제원 장외 채권거래, 한국산업은행 모펀드 성과평가)은
공고문에 '채권평가회사'·'3865' 가 아예 없습니다. 그래서 공고명 점수가 따로 있습니다.

**공고명 점수만 믿어도 안 됩니다.** 그래서 1차 면허제한 조회가 따로 있습니다.

**면허제한 API 만 믿어도 안 됩니다.** 허용업종을 아무것도 적지 않는 공고가
많습니다. 그래서 공고문 PDF 를 열어보는 3·4차가 있습니다.

세 가지가 서로를 메우는 구조입니다. 하나를 빼면 그만큼 놓칩니다.

### 4-6. 이미 알린 공고가 바뀌면 다시 알립니다

**새 공고만 보는 것으로는 모자랍니다.** 마감이 앞당겨졌는데 모르고 있으면
그것도 입찰을 놓치는 길입니다. 그래서 회차마다 **이미 보낸 공고도 다시
견줍니다.**

수집이력(`_수집이력.json`)에 공고번호만이 아니라 **그때의 값**(차수·마감일시·
배정예산·공고명·정확도)을 함께 남깁니다. 다음 회차에 같은 공고가 다시 조회되면
그 값과 견주고, 달라진 것이 있으면 **변경**으로 다시 올립니다.

| 그 공고에 생긴 일 | 어떻게 되나 |
|---|---|
| 값이 그대로 | 아무 줄도 안 남습니다. 메일에도 안 나옵니다 |
| 마감·예산·공고명이 달라짐 | **변경** 으로 엑셀에 한 줄 더, 메일 맨 위 변경표에 |
| 값은 같은데 차수만 오름 | **변경**(`재게시`). 규격서·첨부만 고친 경우입니다 |
| 취소공고가 뜸 | **취소** 로 알리고 **수집이력에서 뺍니다** (되풀이 방지) |

- **왜 API 가 안 알려주나** — 나라장터는 '이 공고가 변경공고다' 까지만 알려주고
  무엇이 바뀌었는지는 말해주지 않습니다. 변경일시(`chgDt`)는 1,500건 중 1건만
  채워져 있어 쓸 수 없습니다. 그래서 **우리가 적어둔 값과 직접 견줍니다**
- **엑셀은 지우지 않고 아래에 쌓습니다.** 한 공고가 신규 → 변경 → 취소로
  세 줄이 됩니다. 공고번호로 필터를 걸면 그 공고의 이력이 그대로 보입니다
- **변경된 건은 점수와 무관하게 알립니다.** 이미 한 번 보낸 공고라, 지금
  점수가 문턱 아래로 내려갔더라도 '그 공고가 바뀌었다' 는 알려야 합니다.
  이때는 지난 회차의 정확도를 그대로 씁니다
- **재공고는 변경이 아닙니다.** 재공고는 **새 공고번호**를 받으므로 우리 눈에는
  새 공고입니다. `공고종류` 에 `재공고` 라고만 표시하고, 원래 공고와 이어붙이지는
  않습니다

> **처음 한 회차는 변경이 안 잡힙니다.** 예전 수집이력에는 공고번호만 있고
> 값이 없어서 견줄 것이 없습니다. 그 회차에 값을 채우고, **다음 회차부터**
> 변경을 잡습니다. 모르는 것을 '변경' 이라고 말하지 않기 위해서입니다.

### 4-7. '공고가 없음' 과 '수집이 실패함' 은 다른 메일로 옵니다

둘이 똑같이 생기면, API 가 죽은 날에도 받는 사람은 **'오늘은 공고가 없었구나'**
로 읽습니다. 그게 곧 입찰 누락입니다. 그래서 회차마다 상태를 셋으로 가릅니다.

| 상태 | 어떤 메일이 오나 | 누구에게 |
|---|---|---|
| **정상** | 평소 메일. 0건이면 '특이사항 없습니다' | 받는 사람 |
| **일부실패** | 제목 끝에 `— 일부 조회 실패`, 본문 맨 위에 **빨간 경고 상자**와 못 받은 구간 | 받는 사람 |
| **완전실패** | 결과 메일을 **보내지 않고** 오류 메일만 | 오류 메일 받는 사람 |

- **일부실패가 완전실패보다 위험합니다.** 한 구간만 못 받아도 메일은
  '오늘 3건' 이라고 멀쩡히 나가지만, 사실은 '10건 중 3건' 일 수 있습니다.
  그래서 0건이어도 조회가 불완전했으면 '없습니다' 라고 하지 않습니다
- **완전실패는 목록 조회(용역·물품·공사)가 전부 실패한 경우**입니다.
  면허제한만 끊긴 것은 일부실패입니다. 수집은 돌아가지만 A등급을 놓칠 수
  있어서입니다
- 오류 메일에는 **그 회차를 다시 돌리는 명령**이 그대로 들어 있습니다.
  조회기간은 실행할 때마다 앞으로 밀리므로, 내일 그냥 다시 돌려도 오늘
  놓친 공고는 안 잡힙니다. `--기준` 으로 그 시각을 다시 훑어야 합니다

**회차별 조회 기록** — 결과 폴더의 `_조회기록.csv` 에 한 회차 한 줄씩 쌓입니다.
`실행일시 · 조회기간 · 상태 · 조회(면허제한/용역/…) · 건수 · 못받은구간 · 수집건수`
입니다. 실행.log 는 회차마다 수십 줄이라 **'지난 두 주 동안 몇 번 실패했나'**
를 볼 수 없어서 따로 둡니다. 엑셀에서 바로 열립니다.

> **메일 자체가 막혀 있으면 오류 메일도 못 나갑니다.** (아웃룩이 꺼져 있는
> 그 경우 — 2-4 참고) 그래서 `_조회기록.csv` 가 마지막 보루입니다.
> 그리고 `신규 0건일 때도 보내기` 를 켜 두는 편이 안전합니다. 매 회차 한 통씩
> 오면 **아무 메일도 안 온 날** 자체가 이상 신호가 되기 때문입니다.

### 4-8. 엑셀 컬럼과 PDF 파일명

**엑셀 컬럼**

| 정확도 | 공고종류 | 변경내역 | 등록일 | 수요기관 | 공고기관 | 공고명 | 마감일시 | 배정예산 | 추정가격 | 업무 | 점수 | 키워드 | 근거 | 첨부 | 출처 | 공고번호 | 링크 | 수집일시 |

- **정확도** — A·B 는 수집분, **C 는 검토 필요분**이고 **행 전체가 회색**입니다.
  이 칸에 자동 필터가 걸려 있어 C만 골라 보거나 빼고 볼 수 있습니다
- **공고종류** — `신규` / `변경` / `재공고` / `취소`
  - 나라장터가 공고마다 달아주는 값을 그대로 받아 적습니다.
    8/12~8/18 용역공고 1,500건 기준으로 신규 1,054 · 재공고 285 · 변경 87
  - 단 **변경내역이 채워진 줄은 무조건 `변경`** 입니다. 우리 수집이력과
    견줘 실제로 달라진 건이라는 뜻이라 나라장터 표기보다 우선합니다
- **변경내역** — **이미 메일로 알린 공고가 나중에 바뀌었을 때만** 채워집니다.
  처음 보는 공고는 항상 빈칸입니다 (견줄 지난 값이 없으니까요)
  - `마감 2026-08-26 10:00 → 2026-09-02 10:00`
  - `예산 210,000,000 → 240,000,000`
  - `공고명 바뀜`
  - `재게시 (차수 000 → 002, 목록에 보이는 값은 그대로)`
    — 규격서나 첨부만 고친 경우입니다. 목록 API 로는 무엇이 바뀌었는지
    알 수 없으니 **공고문을 다시 열어보셔야 합니다**
  - `공고 취소됨`
- **출처** — 지금은 모두 `나라장터` 입니다. 기관 자체 홈페이지까지 보게 되면
  여기가 늘어납니다. 나중에 컬럼을 새로 넣으면 이미 쌓인 엑셀을 다 옮겨야
  해서 지금 한 칸 잡아뒀습니다
- **배정예산 · 추정가격** — 둘 다 공고에 적힌 금액이고 뜻이 다릅니다.
  - **배정예산** — 발주기관이 이 사업에 잡아둔 돈. **부가세를 포함**합니다
  - **추정가격** — 입찰의 기준이 되는 금액. **부가세를 뺀** 금액입니다
  - 메일 본문의 `사업예산` 은 이 중 **배정예산**입니다
  - 숫자로 들어가므로 엑셀에서 정렬·합계가 됩니다. 공고에 금액이 안 적혀
    있으면 0 이 아니라 **빈칸**입니다 (1,500건 중 6건)
- **점수** — 공고명 기반 점수. 메일에는 안 나오고 엑셀에만 있습니다.
  점수표를 다듬을 때 쓰는 값입니다
- **키워드** — `업종코드 3865` / `채권평가회사` / `3864` / `-`
- **근거** — 왜 그 판정이 나왔는지 그대로 보여줍니다. 점수표를 고칠 때 이걸 보세요
  - B·C: `확정: 공정가치평가 · 대상: 대체투자자산 · 조합+4 · 기관+3`
  - A(면허제한): `면허제한(3개 허용): 채권평가회사/3865, 회계법인/1200, 종합금융투자사업자/7096`
    허용업종을 **전부** 적되 우리가 걸린 업종을 맨 앞에 놓습니다.
    허용업종이 여러 개면 회계법인·신용평가사 등과 경쟁하는 공고라는 뜻입니다.
    **메일에는 이 뒷부분이 안 나옵니다.** 훑어볼 때는 군더더기라서,
    경쟁 구도를 볼 때만 엑셀에서 확인합니다
- **첨부** — 그 공고에 달린 첨부파일 개수 (받는 건 공고문 PDF 하나뿐입니다)
- **수집일시** — 이 줄을 만든 실행 시각. 한 번 실행분은 전부 같은 값이라
  **"어제 배치에서 새로 올라온 것만"** 을 필터로 골라볼 수 있습니다

**공고문 PDF**

엑셀에 오른 건만, **한 건당 한 개**만 받습니다. 파일명은
`기관_공고명_공고번호.pdf` 입니다.

- 기관은 **수요기관**을 씁니다. 조달청 대행 공고는 공고기관이 전부 '조달청' 이라
  파일명으로 구분이 안 되기 때문입니다. 수요기관이 비어 있으면 공고기관을 씁니다
- 공고번호를 붙이는 이유는 같은 기관이 같은 이름으로 재공고하는 일이 흔해서입니다.
  안 붙이면 앞 건을 덮어씁니다
- 첨부가 여러 개면 **자격요건 키워드가 나온 문서**를, 아무 데서도 안 나왔으면
  **첫 번째 PDF**(보통 입찰공고문)를 남깁니다
- HWP·ZIP 등 나머지 첨부는 받지 않습니다. 필요하면 엑셀의 **링크** 칸에서
  나라장터 공고 화면을 열면 됩니다

### 4-9. 알아두면 좋은 것

**"마감일시" 는 입찰서 제출 마감일시(`bidClseDt`)입니다.** 협상에 의한 계약에서는
대개 제안서 마감과 같지만 별도로 정해진 경우가 있습니다.
실제 제출 전에는 공고문 원문을 반드시 확인하세요.

**`2026-08-21 09:00 (개찰)` 처럼 뒤에 (개찰) 이 붙은 것**은 마감일시가 아니라
개찰일시입니다. 직찰·우편 방식 공고는 전자입찰 마감시각이 아예 없어서
나라장터 화면에서도 입찰마감일시가 공란입니다. 빈칸으로 두면 놓치기 쉬워
개찰일시를 대신 넣되 표시해 둡니다. **이 경우 제출 마감은 공고문에서
반드시 확인해야 합니다.** 용역 공고의 14% 정도가 여기 해당합니다.

**PDF 검사는 PDF 첨부만 봅니다.** HWP 는 읽지 못합니다.
자격요건이 HWP 제안요청서에만 있으면 4차에서 못 잡습니다.
이것도 공고명 점수와 1차 면허제한이 따로 있는 이유입니다.
스캔본이라 본문 텍스트가 아예 없는 공고문도 같은 이유로 못 읽습니다.

**엑셀을 열어둔 채로 실행하면 저장이 안 됩니다.** 공고문 PDF 는 정상적으로
받아지지만 엑셀 기록이 빠지니, 자동 실행 시간대에는 닫아두세요.
메일 본문은 그대로 나갑니다(내용은 메모리에서 만듭니다). 다만 **첨부된 엑셀은
이번 회차가 빠진 이전 파일**이니, 그럴 때는 본문 표를 보세요.

**`_수집이력.json` 을 지우면** 그동안 받은 공고를 처음부터 다시 받습니다.
점수표를 크게 고친 뒤 다시 판정하고 싶을 때 씁니다. 다만 **메일도 그만큼
한꺼번에 나가므로** 지운 뒤에는 메일을 끈 채로 한 번 돌리세요.

**엑셀 컬럼 구성이 바뀌면** 기존 파일을 `공고목록_이전_날짜.xlsx` 로 옮겨두고
새로 시작합니다. 값이 한 칸씩 밀린 채 쌓이는 것을 막기 위한 것으로,
옮겨둔 파일은 그대로 열어볼 수 있습니다.

## 5. 안 될 때

| 증상 | 원인 |
|---|---|
| exe 를 눌렀는데 **검은 창만 깜빡이고 꺼짐** | `_internal` 폴더가 없거나 지워졌습니다. 받은 폴더를 통째로 다시 받으세요 ([1](#1-받은-폴더)) |
| 백신이 exe 를 지우거나 격리함 | 사내 IT 에 예외 등록을 요청하세요. 넘겨준 담당자에게도 알려주세요 |
| exe 를 눌렀는데 브라우저가 안 열림 | 검은 창의 메시지를 보세요. `config.yaml` 이나 `점수표.yaml` 의 문법이 틀리면 몇 번째 줄인지 나옵니다 ([3-9](#3-9-yaml-을-직접-고쳐야-할-때)) |
| `응답이 JSON이 아닙니다` | 인증키 오류. Encoding 말고 **Decoding** 키인지 확인 |
| `403` | 인증키 오류이거나 활용신청 미승인 |
| `API 응답 22` / `429` | 일일 호출 한도 초과. 내일 다시 |
| `전체 0건` | 인증키가 아직 승인 전이거나 조회 범위가 짧음 |
| 수집 0건인데 공고는 많음 | 편집기의 **검증 실행** 으로 점수표부터 확인 |
| 편집기가 `저장하지 못했습니다` | **파일은 그대로입니다.** 그 항목만 메모장으로 고치세요 ([3-9](#3-9-yaml-을-직접-고쳐야-할-때)) |
| 설정을 고쳤는데 수집 결과가 그대로 | 편집기에서 **저장**을 눌렀는지 확인. 고친 것은 다음 실행부터 반영됩니다 |
| 설정을 고쳤는데 아무 반영이 안 됨 | `_internal` **안**의 파일을 고치지 않았는지 확인. 설정은 `_internal` **바깥**, exe 옆의 것을 고쳐야 합니다 |
| 메모장으로 고친 뒤 한글이 깨짐 | `ANSI` 로 저장한 것입니다. `백업\` 에서 되돌리고 인코딩을 `UTF-8` 로 다시 저장 |
| 면허제한 조회가 자꾸 끊김 | 기간을 7일씩 나눠 실행. 캐시가 남아 이어집니다 |
| 메일이 안 감 (`mail.to 가 비어 있어`) | 메일 탭의 **받는 사람**에 주소를 넣고 **메일 발송**을 켜세요 ([3-1](#3-1-메일-켜기끄기-메일만-보내기)) |
| `아웃룩 발송 —` 오류 | 아웃룩을 먼저 실행. 그래도 안 되면 보안 정책 문제이므로 **발송 방식**을 `smtp` 로 ([3-3](#3-3-발송-방식-아웃룩--smtp)) |
| `mail.smtp 의 host / from 이 비어` | 사내 SMTP 정보를 IT 에서 받아 메일 탭 **SMTP** 묶음의 **서버 주소** · **발신 주소** 에 넣으세요 |
| 첫 실행 때 오래된 공고가 무더기로 메일에 옴 | 수집 이력이 없어서 그렇습니다. 정상입니다. 다음 회차부터는 신규만 나갑니다 ([2-3](#2-3-시험-삼아-한-번-돌려보기)) |
| 자동 실행이 안 돎 | **`로그\실행.log` 에 그 시각 헤더가 있는지부터 확인.** 없으면 프로그램이 시작조차 못 한 것이므로 `로그\오류.log` 를, 있으면 작업 스케줄러의 "사용자가 로그온할 때만 실행" · 배터리 설정을 보세요 |
| 스케줄러 작업이 계속 "실행 중" | 오류 후 `pause` 에서 멈춘 것. `/tr` 의 경로 뒤에 `auto` 인자가 붙었는지 확인 ([2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러)) |
| 폴더를 옮겼더니 자동 실행이 안 됨 | 스케줄러에 예전 경로가 남아 있습니다. 다시 등록하세요 ([2-7](#2-7-다른-pc로-옮길-때)) |
| 공유폴더에 저장이 안 됨 | **결과 저장 폴더** 를 `Z:` 같은 드라이브 문자 대신 `\\서버이름\...` 으로 ([3-7](#3-7-저장-위치-네트워크-공유폴더)) |

## 부록 A. 명령으로 실행하기 (선택)

**여기는 안 봐도 됩니다.** [2](#2-설치) 대로 설치했으면 자동 실행은
작업 스케줄러가, 손으로 돌리는 것은 편집기의 **수동 실행** 탭이 합니다.
명령 프롬프트에 익숙한 사람이 같은 일을 더 빨리 하고 싶을 때만 쓰세요.

받은 폴더에서 명령 프롬프트를 열고(주소창에 `cmd` 를 치면 됩니다) 씁니다.

```
나라장터수집기.exe                    설정 편집기를 브라우저에 엽니다
나라장터수집기.exe 수집               설정된 조회 기간만큼 (자동 실행과 같음)
나라장터수집기.exe 수집 30            최근 30일
나라장터수집기.exe 수집 30 --목록만    PDF 저장 없이 엑셀만 (점수표 다듬을 때)
나라장터수집기.exe 수집 --pdf없이      PDF 검사 생략 (빠름, 1·2차만)
나라장터수집기.exe 수집 --메일없이     메일 발송만 건너뛴다
나라장터수집기.exe 수집 --메일만       수집 없이 엑셀의 마지막 회차를 메일로
나라장터수집기.exe 점수표검증          점수표가 아직 맞는지 검사
```

지난 회차를 재현해 볼 수도 있습니다. 그날 그 시각에 돌렸다면 어떤 메일이
나갔을지 확인할 때 씁니다.

```
나라장터수집기.exe 수집 0.75 --기준 "2026-08-06 10:00" --저장 ./재현확인
```

편집기의 **수동 실행** 탭 화면과 명령은 이렇게 짝지어집니다.

| 화면 | 같은 명령 |
|---|---|
| 조회 범위 `설정된 조회 기간 그대로` | `나라장터수집기.exe 수집` |
| 조회 범위 `최근 30일` | `나라장터수집기.exe 수집 30` |
| 조회 범위 `기준시각 …부터 거슬러 0.75일` | `나라장터수집기.exe 수집 0.75 --기준 "…"` |
| 옵션 `PDF 저장 안 함` | `--목록만` |
| 옵션 `PDF 검사 생략` | `--pdf없이` |
| 옵션 `메일 보내지 않음` (기본 켜짐) | `--메일없이` |
| `저장 폴더` 칸 | `--저장 …` |
| `마지막 회차 메일만 보내기` 버튼 | `--메일만` |
| `검증 실행` 버튼 | `나라장터수집기.exe 점수표검증` |

**그래도 화면으로 하는 편이 안전합니다.** 두 가지가 다릅니다.

- **메일이 실제로 나가는 실행인지 실행 전에 알려줍니다.** 받는 사람까지
  빨간 줄로 보여주므로, 시험 삼아 돌렸다가 팀 전체에 메일이 나가는 일이 없습니다
- **기준시각을 넣으면 저장 폴더를 `./재현_20260806_1000` 으로 자동으로 채웁니다.**
  명령줄에서 `--저장` 을 빠뜨리면 재현 결과가 진짜 `_수집이력.json` 과
  `공고목록.xlsx` 에 섞여 들어갑니다

## 부록 B. 실행.bat 안쪽

**여기도 안 봐도 됩니다.** 이 파일은 고칠 데가 없습니다.
스케줄러가 왜 exe 가 아니라 이 배치를 부르는지 궁금할 때만 보세요.

```bat
@echo off
setlocal
cd /d "%~dp0"

set PYTHONUTF8=1
set PYTHONIOENCODING=utf-8

if not exist "로그" md "로그"

"%~dp0나라장터수집기.exe" 수집 2> "로그\오류.log"

set RC=%ERRORLEVEL%

if not "%RC%"=="0" (
    echo.
    echo ============================================
    echo  오류가 발생했습니다. 종료코드 %RC%
    echo  자세한 내용은 로그\오류.log 를 확인하세요.
    echo ============================================
    if /i not "%~1"=="auto" pause
)

exit /b %RC%
```

실제 파일에는 `rem` 주석 줄이 더 붙어 있습니다.

각 줄이 왜 이렇게 되어 있는지:

- **`"%~dp0나라장터수집기.exe" 수집`** — `%~dp0` 는 이 배치가 놓인 폴더입니다.
  절대경로를 적어두지 않으므로 **폴더를 통째로 옮겨도 이 파일은 고칠 필요가
  없습니다.** 뒤의 `수집` 이 없으면 편집기가 열립니다
- **`2> "로그\오류.log"`** — 프로그램이 **아예 못 뜨는** 경우를 잡습니다.
  정상이면 0바이트 빈 파일입니다. 실행 기록 자체는 수집기가
  `로그\실행.log` 에 직접 남깁니다([2-5](#2-5-만들어지는-것) 참고).
  **두 파일을 하나로 합치면 안 됩니다.** cmd 가 리다이렉트로 파일을 잠근 사이
  프로그램이 같은 파일을 열지 못해 실행 기록이 통째로 빕니다
- **`auto` 인자** — 작업 스케줄러가 붙여줍니다([2-4](#2-4-윈도우-자동-실행-설정-작업-스케줄러)).
  오류가 나도 `pause` 에서 멈추지 않게 해서, 아무도 없는 시간에 창이 떠 있는 채로
  다음 실행이 막히는 것을 막습니다. 사람이 더블클릭할 때는 인자가 없으므로
  오류 메시지를 읽을 수 있게 멈춥니다
- **`exit /b %RC%`** — 실제 종료 코드를 작업 스케줄러에 넘깁니다. 이게 없으면
  실패해도 스케줄러 기록에 **"마지막 실행 결과: 0(성공)"** 으로 남아 실패를
  알아챌 수 없습니다

> **이 파일을 메모장으로 열어 저장했다면 인코딩을 확인하세요.**
> **CP949(ANSI) + CRLF** 여야 합니다. UTF-8 로 저장하면 cmd 가 배치 파일을
> 읽는 위치를 잃어버려 **명령이 앞부분부터 잘린 채 실행됩니다.**
> 메모장이면 다른 이름으로 저장 → 인코딩 `ANSI` 입니다.
> 애초에 고칠 일이 없는 파일이니 열지 않는 것이 가장 안전합니다.
