# 나라장터 채권평가회사 공고 수집기

채권평가회사(업종코드 3865)가 맡을 수 있는 입찰공고를 매일 자동으로 찾아
**엑셀에 기록**하고 **메일로 공지**합니다. 엑셀에 오른 건은
**공고문 PDF 도 한 개씩** 받아둡니다.

## 1. 파일 구성

> **exe 배포판(`나라장터 수집기` 폴더)을 받았다면 이 절은 건너뛰세요.**
> 아래 파일들은 전부 `_internal` 안에 들어 있어 열어볼 일이 없습니다.
> [2-0](#2-0-exe-배포판을-받았다면) 으로 가세요.

소스로 받았다면 아래 열한 개를 **같은 폴더에 함께** 두세요.

| 파일 | 역할 | 고칠 일 |
|---|---|---|
| `실행.bat` | **더블클릭하면 수집이 돕니다** | 다른 PC로 옮길 때 파이썬 경로 한 줄 ([2-6](#2-6-실행bat-준비하기)) |
| `편집기.bat` | **더블클릭하면 설정을 고치고 수집을 돌릴 수 있습니다** | 다른 PC로 옮길 때 파이썬 경로 한 줄 |
| `수집기.py` | 매일 돌리는 본체 | 없음 |
| `점수.py` | 점수표를 읽어 채점 | 없음 |
| `편집기.py` | 편집기 본체 | 없음 |
| `앱경로.py` | 설정·결과가 어느 폴더에 있는지 정하는 곳 | 없음 |
| `점수표.yaml` | **공고명 점수표(키워드)** | 자주. `편집기.bat` 으로 고칩니다 |
| `config.yaml` | 인증키·기간·저장위치·**메일** | 처음 한 번. `편집기.bat` 으로 |
| `config.example.yaml` | `config.yaml` 견본 | 없음. 망가졌을 때 되돌릴 원본입니다 |
| `점수표_검증.py` | 점수표를 고친 뒤 돌리는 검사 | 놓친 공고가 생기면 목록에 추가 |
| `README.md` | 이 문서 | — |

exe 로 묶어 넘길 때만 쓰는 파일이 세 개 더 있습니다
([부록 C](#부록-c-exe-로-묶어-배포하기)). 소스로 돌릴 때는 없어도 됩니다.

| 파일 | 역할 |
|---|---|
| `빌드.bat` | 더블클릭하면 exe 배포판을 만듭니다 |
| `나라장터수집기.spec` | 무엇을 어떻게 묶을지 적은 설정 |
| `실행진입.py` | exe 의 진입점. 첫 인자로 편집기/수집을 가릅니다 |
| `배포\실행.bat` | 배포판에 들어갈 `실행.bat`. exe 를 부릅니다 |

**평소에 쓰는 것은 맨 위의 두 개뿐입니다.** 자동 수집은 `실행.bat`(작업 스케줄러가
돌립니다), 설정 변경과 손으로 돌려보는 것은 `편집기.bat` 입니다. 나머지는 그
둘이 알아서 불러 씁니다.

**이 열한 개가 전부입니다.** 폴더 위치는 어디든 상관없고, 파일들이 서로를
찾을 때 자기가 놓인 폴더만 봅니다. 결과가 쌓일 폴더와 실행 기록이 쌓일
`로그/` 폴더는 첫 실행 때 자동으로 만들어집니다([2-8](#2-8-만들어지는-것) 참고).

- `수집기.py` 는 `점수.py` 를, `점수.py` 는 `점수표.yaml` 을 읽습니다.
  이 셋 중 하나라도 빠지면 실행되지 않습니다
- `앱경로.py` 는 셋 다 읽습니다. 빠지면 `ModuleNotFoundError: 앱경로` 가 납니다
- `점수표_검증.py` 는 검증용 공고 8건을 파일 안에 갖고 있어 따로 필요한
  자료가 없습니다
- `python` 실행 후 생기는 `__pycache__/` 폴더는 그냥 두면 됩니다

## 2. 실행 방법

처음 설치하는 것이라면 **2-1 부터 2-7 까지 순서대로** 하면 됩니다.
다 하면 평일 오전 10시·오후 4시에 알아서 돌고, 결과가 엑셀에 쌓이고
메일이 나갑니다.

| | 단계 | 하는 일 |
|---|---|---|
| **준비** | [2-1](#2-1-파이썬-설치) 파이썬 설치 | 한 번만 |
| | [2-2](#2-2-패키지-설치) 패키지 설치 | 명령 한 줄 |
| | [2-3](#2-3-인증키-발급) 인증키 발급 | data.go.kr 가입 |
| **설정** | [2-4](#2-4-설정-채우기-편집기bat) 설정 채우기 | `편집기.bat` 더블클릭 |
| | [2-5](#2-5-시험-삼아-한-번-돌려보기) 시험 실행 | 잘 도는지 확인 |
| **자동화** | [2-6](#2-6-실행bat-준비하기) `실행.bat` 준비 | 파이썬 경로 한 줄 |
| | [2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러) 작업 스케줄러 등록 | 명령 두 줄 |

**명령 프롬프트는 설치(2-1·2-2)와 자동화(2-6·2-7) 에서만 씁니다.**
설정과 시험 실행은 전부 `편집기.bat` 을 더블클릭해서 화면으로 합니다.
명령으로 직접 돌리는 방법은 따로 [부록 A](#부록-a-명령으로-실행하기-선택) 에 있습니다.
설치가 끝난 뒤 무엇이 생기는지는 [2-8](#2-8-만들어지는-것), 다른 PC 로 넘길 때는
[2-9](#2-9-다른-pc로-다시-넘길-때) 를 보세요.

### 2-0. exe 배포판을 받았다면

**`나라장터 수집기` 라는 폴더를 통째로 받았다면 파이썬을 깔 필요가 없습니다.**
폴더 안에 파이썬과 패키지가 이미 들어 있습니다.

| | 배포판(exe) | 소스(.py) |
|---|---|---|
| 파이썬 설치 [2-1](#2-1-파이썬-설치) | **필요 없음** | 필요 |
| 패키지 설치 [2-2](#2-2-패키지-설치) | **필요 없음** | 필요 |
| 인증키 [2-3](#2-3-인증키-발급) | 필요 | 필요 |
| 설정 [2-4](#2-4-설정-채우기-편집기bat) | `나라장터수집기.exe` 더블클릭 | `편집기.bat` 더블클릭 |
| `실행.bat` 고치기 [2-6](#2-6-실행bat-준비하기) | **필요 없음** (파이썬 경로 줄이 없습니다) | 필요 |
| 스케줄러 [2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러) | 필요 | 필요 |

즉 **[2-3](#2-3-인증키-발급) → [2-4](#2-4-설정-채우기-편집기bat) → [2-5](#2-5-시험-삼아-한-번-돌려보기) → [2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러)** 네 단계만 하면 됩니다.

받은 폴더는 이렇게 생겼습니다.

```
나라장터 수집기\
├─ 나라장터수집기.exe    ← 더블클릭하면 설정 화면이 브라우저에 열립니다
├─ 실행.bat              ← 자동 실행이 쓰는 파일. 열어볼 일 없습니다
├─ 설명서.pdf            ← 이 문서
└─ _internal\            ← 파이썬과 패키지. 절대 지우지 마세요
```

**처음 실행하면 `config.yaml` 과 `점수표.yaml` 이 옆에 새로 생깁니다.**
설정이 여기 저장됩니다. 돌리고 나면 `수집결과`·`로그`·`백업` 폴더도 생깁니다.
[2-8](#2-8-만들어지는-것) 과 같습니다.

**`_internal` 폴더는 건드리지 마세요.** 지우거나 옮기면 실행되지 않습니다.
설정은 전부 `_internal` 바깥, exe 와 같은 자리에 있습니다.

> **프로그램을 새 버전으로 바꿀 때**는 `나라장터수집기.exe` 와 `_internal` 폴더만
> 덮어쓰면 됩니다. `config.yaml`·`점수표.yaml` 은 이미 있으면 덮어쓰지 않으므로
> 고쳐 둔 설정이 그대로 남습니다.

[2-4](#2-4-설정-채우기-편집기bat) 이후로는 `편집기.bat` 이라고 적힌 곳을
`나라장터수집기.exe` 로 바꿔 읽으면 나머지는 전부 같습니다.
exe 를 만드는 쪽은 [부록 C](#부록-c-exe-로-묶어-배포하기) 를 보세요.

### 2-1. 파이썬 설치

python.org 에서 **3.10 이상**을 받습니다.
설치 첫 화면에서 **Add Python to PATH** 를 반드시 체크하세요.
(체크를 놓치면 나중에 `pip: 명령을 찾을 수 없음` 이 납니다. 재설치하면 됩니다.)

설치 후 명령 프롬프트에서 확인합니다.

```
python --version
```

### 2-2. 패키지 설치

```
pip install requests pyyaml openpyxl pypdf pywin32
```

| 패키지 | 없으면 |
|---|---|
| `requests` `pyyaml` `openpyxl` | 아예 실행되지 않습니다 |
| `pypdf` | 공고문 PDF 검사(3·4차)를 건너뜁니다. 넣는 편이 좋습니다 |
| `pywin32` | **아웃룩으로 메일을 못 보냅니다** (`mail.mode: outlook` 일 때만 필요) |

`pywin32` 는 윈도우 전용입니다. `mail.mode: smtp` 로 보내거나 메일을
안 쓸 거면 없어도 됩니다.

### 2-3. 인증키 발급

1. https://www.data.go.kr 가입 후 로그인
2. **조달청_나라장터 입찰공고정보서비스** 검색 → 활용신청 (자동승인)
3. 마이페이지 > 데이터활용
4. '개인 API 인증키' 항목에서 인증키 복사(**Decoding**)

**인증키는 쓰는 PC마다 따로 발급받으세요.** 일일 호출 한도가 키 단위로
걸리기 때문에, 같은 키를 두 사람이 쓰면 한쪽이 한도를 다 쓴 날 다른 쪽도
같이 멈춥니다. 발급은 자동승인이라 몇 분이면 끝납니다.

### 2-4. 설정 채우기 (편집기.bat)

**`편집기.bat` 을 더블클릭합니다.** 검은 창이 하나 뜨고, 잠시 뒤 브라우저가
저절로 열립니다. 이 화면에서 설정을 채우면 오타로 파일이 깨질 일이 없습니다.

> 검은 창은 **닫지 마세요.** 그 창이 편집기입니다. 다 쓰고 나면 검은 창에서
> Ctrl+C 를 누르거나 창을 닫으면 편집기가 꺼집니다.
> 브라우저가 안 열리면 검은 창의 메시지를 보세요([5. 안 될 때](#5-안-될-때)).

`config.yaml` 탭에서 아래 세 가지를 채우고 맨 아래 **저장**을 누릅니다.

| 편집기에서 | 무엇을 넣나 |
|---|---|
| **data.go.kr 인증키** | [2-3](#2-3-인증키-발급) 에서 복사한 키를 붙여넣습니다 |
| **결과 저장 폴더** | 기본값 `./수집결과` 그대로 두면 됩니다 |
| **받는 사람** | 공지 메일을 받을 주소. **처음에는 본인 주소 하나만** 넣으세요 |

나머지 항목은 전부 기본값 그대로 두면 됩니다. 조회 기간·대상 기관·메일 문구
같은 것은 나중에 [3. 설정할 수 있는 것들](#3-설정할-수-있는-것들) 을 보고
고치면 됩니다. 편집기로 할 수 있는 다른 일들은
[3-0](#3-0-편집기로-고치기-권장) 에 정리돼 있습니다.

`config.yaml` 이 아예 없으면 같은 폴더의 `config.example.yaml` 을 복사해서
이름을 `config.yaml` 로 바꾸고 다시 여세요.
편집기를 쓰지 않고 메모장으로 직접 고치는 방법은
[3-9](#3-9-yaml-을-직접-고쳐야-할-때) 에 있습니다.

### 2-5. 시험 삼아 한 번 돌려보기

설정이 맞는지 여기서 확인합니다. 편집기 화면 위쪽의 **실행** 탭에서 합니다.

1. **실행** 탭을 누릅니다
2. 조회 범위에서 **`최근 [ 3 ] 일`** 을 고릅니다
3. 옵션의 **`메일 보내지 않음`** 이 켜져 있는지 확인합니다 (기본으로 켜져 있습니다)
4. **실행** 버튼을 누릅니다. 진행 기록이 화면에 그대로 나옵니다
5. 끝나면 `수집결과` 폴더에 `공고목록.xlsx` 가 생겼는지 열어봅니다

**처음부터 기간을 길게 잡지 마세요.** 4개월치는 면허제한 조회만 300회가 넘어
오래 걸리고 중간에 끊기기 쉽습니다. 3~7일로 시작하면 몇 분이면 끝납니다.

실행 버튼 위에는 **실제로 돌아갈 명령줄이 그대로** 나오고, 메일이 진짜
나가는 실행이면 **받는 사람까지 빨간 줄로** 미리 알려줍니다. 시험 삼아
돌렸다가 팀 전체에 메일이 나가는 일이 없습니다.

**메일까지 시험해 보려면** 아웃룩에 초안만 띄워놓고 확인하는 방법이 있습니다.
[3-1](#3-1-메일-켜기끄기-메일만-보내기) 아래쪽의 4단계를 따라 하세요.

`0건`이 나와도 정상일 수 있습니다. 3일 안에 해당하는 공고가 없으면 그렇습니다.
공고는 많은데 계속 0건이면 [5. 안 될 때](#5-안-될-때) 를 보세요.

### 2-6. 실행.bat 준비하기

자동 실행은 편집기가 아니라 **`실행.bat`** 이 합니다. 작업 스케줄러가
정해진 시각에 이 파일을 더블클릭해 주는 셈입니다. 등록하기 전에 이 파일이
그 PC에서 제대로 도는지 맞춰둡니다.

**① 파이썬 경로 한 줄을 이 PC 것으로 고칩니다.**

명령 프롬프트에서 경로를 확인하고,

```
where python
```

`실행.bat` 을 메모장으로 열어 아래 줄의 경로를 나온 값으로 바꿉니다.
`편집기.bat` 에도 똑같은 줄이 있으니 같이 고치면 됩니다.

```bat
set "PY=C:\Users\user\AppData\Local\Python\pythoncore-3.14-64\python.exe"
```

경로가 틀려도 `python` 으로 넘어가 **당장은 돌지만**, 그 `python` 이
마이크로소프트 스토어 별칭이면 **작업 스케줄러에서만 조용히 실패합니다.**
그래서 미리 맞춰둡니다.

**② 저장할 때 인코딩을 반드시 확인하세요.**

> **`실행.bat` 은 CP949(ANSI) 인코딩 + CRLF 줄바꿈으로 저장해야 합니다.**
> UTF-8 로 저장하면 cmd 가 배치 파일을 읽는 위치를 잃어버려 **명령이 앞부분부터
> 잘린 채 실행됩니다.** 실제로 `python 수집기.py` 가 `thon 수집기.py` 로 잘려서
> 자동 수집이 파이썬을 띄우지도 못하고 끝난 적이 있습니다.
> 메모장이면 **다른 이름으로 저장 → 인코딩 `ANSI`**, VS Code 면 오른쪽 아래에서
> 인코딩 `CP949` · 줄바꿈 `CRLF` 입니다. 안에 `chcp` 줄을 넣어도 같은 증상이 납니다.

**③ 더블클릭해서 확인합니다.** 검은 창이 뜨고 수집이 돌면 준비가 끝난 것입니다.
이때는 [2-5](#2-5-시험-삼아-한-번-돌려보기) 의 시험 실행과 달리 `config.yaml` 의
`hours` 조건으로 **진짜 수집이 돌고 메일도 나갑니다.** 아직 메일을 보내고
싶지 않으면 편집기에서 `mail.enabled` 를 잠깐 꺼두고 누르세요.

배치 파일 안이 왜 그렇게 생겼는지는 [부록 B](#부록-b-실행bat-안쪽) 에 있습니다.
평소에는 볼 일이 없습니다.

### 2-7. 윈도우 자동 실행 설정 (작업 스케줄러)

**운영 일정: 평일 오전 10시 / 오후 4시, 주말 없음.**

```
나라장터 공고수집 오전    월~금 10:00
나라장터 공고수집 오후    월~금 16:00
```

다시 등록하거나 다른 PC로 옮길 때는 **명령 프롬프트를 관리자 권한으로 열고**
두 줄이면 됩니다. `C:\...\실행.bat` 은 실제 경로로 바꾸세요.

```
schtasks /create /tn "나라장터 공고수집 오전" /tr "C:\...\실행.bat auto" /sc weekly /d MON,TUE,WED,THU,FRI /st 10:00 /f
schtasks /create /tn "나라장터 공고수집 오후" /tr "C:\...\실행.bat auto" /sc weekly /d MON,TUE,WED,THU,FRI /st 16:00 /f
```

**경로 뒤의 `auto` 를 빼지 마세요.** 이 인자가 없으면 오류가 났을 때 배치가
`pause` 에서 멈춰, 아무도 키를 누르지 않는 동안 작업이 "실행 중" 으로 남고
다음 회차가 시작되지 않습니다([부록 B](#부록-b-실행bat-안쪽) 참고).

화면에서 만들려면 **작업 스케줄러 → 작업 만들기 → 트리거(매주, 월~금, 10:00)
→ 동작(프로그램 시작 → `실행.bat` 선택, 인수 추가에 `auto`)** 순서입니다.

등록한 뒤 **작업 설정에서 확인할 것**

- **"사용자가 로그온할 때만 실행"** — `mail.mode: outlook` 이면 필수입니다.
  로그온 세션이 없으면 아웃룩을 띄울 수 없어 메일만 실패합니다
  (수집과 엑셀 기록은 정상입니다). `schtasks` 로 만들면 기본이 이 설정입니다
- **"가장 빠른 시간에 누락된 작업 시작"** — PC가 꺼져 있어 건너뛴 실행을
  다음 부팅 때 돌립니다. `hours: 168` 이면 늦게 돌아도 놓치는 공고가 없습니다
- **노트북이면 배터리 설정** — 기본값이 "배터리로 실행 중이면 시작 안 함"
  입니다. 등록된 두 작업은 배터리에서도 돌도록 꺼뒀습니다

**주말 제외는 스케줄러가 합니다.** 프로그램에는 요일 개념이 없습니다.
쉬는 날을 바꾸려면 작업 스케줄러에서 트리거의 요일만 고치면 됩니다.

**이 일정에서는 `hours` 를 넓게 잡아야 합니다.** `hours: 12` 로 두면
전날 16시~22시 6시간이 어느 실행에도 안 들어갑니다. 주말에는 금요일 16시부터
월요일 10시까지 **66시간**이 비고, 공휴일이 끼면 90시간이 넘습니다.
그래서 `hours: 168`(7일)로 두고 매번 일주일치를 훑습니다.
겹치는 건 `_수집이력.json` 이 걸러내므로 메일에는 새 공고만 나옵니다.

**여기까지 하면 설치가 끝났습니다.** 다음 실행 시각이 되면 알아서 돌아갑니다.
잘 돌았는지는 `로그\실행.log` 와 결과 폴더로 확인합니다([2-8](#2-8-만들어지는-것)).

### 2-8. 만들어지는 것

```
수집결과/
├── 공고목록.xlsx          ← A·B·C 전부 한 파일 (C는 회색 줄)
├── 공고문/
│   ├── 국민연금공단_국내 대체투자자산(부동산) 공정가치평가_R26BK00123456.pdf
│   └── 사립학교교직원연금공단_대체투자자산 공정가치평가 및 사후모니터링 용역_....pdf
├── _수집이력.json         ← 중복 방지용. 지우지 마세요
└── _면허제한_*.json       ← 면허제한 조회 캐시. 14일 구간마다 한 개
```

엑셀은 실행할 때마다 **아래에 줄이 추가**됩니다. 덮어쓰지 않습니다.

**실행 기록은 `로그/` 에 쌓입니다.**

```
로그/
├── 실행.log              ← 화면에 나온 내용 그대로. 실행할 때마다 누적
├── 실행.log.1            ← 실행.log 가 2MB 를 넘으면 여기로 밀려남
└── 오류.log              ← 파이썬이 아예 못 뜬 경우. 정상이면 0바이트
```

`로그/` 는 `output_dir` 안이 아니라 **`수집기.py` 가 놓인 폴더 옆**에 생깁니다.
저장 위치를 공유폴더로 잡아둔 상태에서 네트워크가 끊기면 그 사실을 기록할
곳까지 같이 사라지기 때문입니다.

- 어떻게 실행했든(더블클릭·명령어·작업 스케줄러) 항상 남습니다.
  실행마다 `==== 실행 2026-08-14 16:00:03  (옵션 없음) ====` 헤더가 붙고,
  붙인 옵션이 그대로 적히므로 **어느 회차가 무슨 조건으로 돌았는지** 알 수 있습니다
- **자동 실행이 의심되면 여기부터 보세요.** 그 시각 헤더가 아예 없으면
  파이썬이 시작조차 못 한 것이므로 `오류.log` 와
  [2-6](#2-6-실행bat-준비하기) 의 인코딩 주의를 확인하면 됩니다
- 지워도 됩니다. 다음 실행 때 다시 만들어집니다

**면허제한 조회는 이어받습니다.** 기간을 길게 잡으면(4개월이면 300회가 넘습니다)
중간에 끊기기 쉬운데, 14일 구간을 하나 받을 때마다 캐시에 남깁니다.
끊겨서 `[경고] 조회가 중간에 끊겨…` 가 뜨면 **같은 명령으로 다시 실행**하세요.
받아둔 구간은 건너뛰고 못 받은 구간부터 이어갑니다.
아직 안 끝난 마지막 구간은 캐시하지 않으므로, 매일 실행에서 오늘 올라온 공고를
놓치는 일은 없습니다.

### 2-9. 다른 PC로 다시 넘길 때

**받는 쪽에 파이썬을 깔 수 없다면 exe 로 묶어 넘기는 편이 훨씬 낫습니다**
([부록 C](#부록-c-exe-로-묶어-배포하기)). 아래 1번과 4번이 통째로 없어집니다.

소스 그대로 넘긴다면 [1. 파일 구성](#1-파일-구성) 의 열 개만 복사하면 됩니다.
결과 폴더는 복사하지 않아도 새로 만들어집니다. 다만 아래 다섯 가지는
파일을 옮긴다고 따라오지 않으니 새 PC에서 다시 해야 합니다.

1. 파이썬 설치와 `pip install` ([2-1](#2-1-파이썬-설치)·[2-2](#2-2-패키지-설치))
2. 인증키 발급 ([2-3](#2-3-인증키-발급) — 키는 PC마다 따로)
3. `config.yaml` 의 `to`·`output_dir` 확인
4. **`실행.bat` 의 `set "PY=..."` 경로**를 그 PC의 파이썬 경로로 수정
   ([2-6](#2-6-실행bat-준비하기). 경로가 틀리면 PATH 의 `python` 으로 넘어가므로
   당장은 돌지만, 스토어 별칭이 걸려 있으면 자동 실행에서 실패합니다)
5. 작업 스케줄러 등록 ([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러) — 경로가 바뀌므로 다시 만들어야 합니다)

**`실행.bat` 을 편집기로 열어 저장했다면 인코딩을 확인하세요.** CP949(ANSI) +
CRLF 가 아니면 자동 실행이 조용히 실패합니다([2-6](#2-6-실행bat-준비하기)).

**담당자를 교체하는 것이라면 결과 폴더도 같이 넘기세요.**
`_수집이력.json` 이 없으면 이미 보냈던 공고를 새 PC가 처음 보는 것으로 여겨,
첫 실행 때 `hours` 기간치가 전부 '신규' 로 한 번에 메일에 실립니다.
결과 폴더를 통째로 옮기면 엑셀도 이어서 쌓입니다.

**두 PC에서 동시에 자동 실행하지 마세요.** 각자 폴더를 쓰면 같은 공고 메일이
두 번 가고, 같은 공유폴더를 쓰면 엑셀과 이력이 깨집니다
([3-7](#3-7-저장-위치-네트워크-공유폴더) 참고).

## 3. 설정할 수 있는 것들

거의 모든 설정은 `config.yaml`, 키워드는 `점수표.yaml` 에 있습니다.
**둘 다 `편집기.bat` 으로 고치면 되고, 파이썬 파일은 건드릴 필요가 없습니다.**
편집기가 안 열리거나 저장이 안 될 때만 메모장으로 직접 고칩니다
([3-9](#3-9-yaml-을-직접-고쳐야-할-때) 참고).

| 무엇을 | 어디를 |
|---|---|
| 인증키 | `config.yaml` > `service_key` |
| 조회 기간 | `config.yaml` > `hours` |
| 조회 업무구분 (용역/물품/공사) | `config.yaml` > `targets` |
| 저장 폴더 | `config.yaml` > `output_dir` |
| 받는 사람, 발송 방식 | `config.yaml` > `mail` |
| 메일 제목·본문 문구 | `config.yaml` > `mail.문구` |
| 대상 기관 | `config.yaml` > `institutions`, `institutions_low_cut` |
| 공고명 키워드·점수 | `점수표.yaml` |

### 3-0. 편집기로 고치기 (권장)

`편집기.bat` 을 더블클릭하면 브라우저가 열리고, `config.yaml` 과 `점수표.yaml`
을 화면에서 고칠 수 있습니다. 들여쓰기나 따옴표를 직접 맞출 필요가 없습니다.
탭은 `점수표.yaml` · `config.yaml` · `실행` 세 개입니다.

```
편집기.bat          (또는  python 편집기.py)
```

주소는 `127.0.0.1` 이라 이 PC 안에서만 열립니다. 창을 닫으려면 검은 창에서
Ctrl+C 를 누르세요.

**메모장으로 고치는 것보다 나은 점**

- **저장하기 전에 점수를 볼 수 있습니다.** 점수표 탭 아래에 공고명과 기관명을
  넣으면 `수집 / 검토 / 제외` 와 점수·근거가 바로 나옵니다. 문턱을 13에서
  15로 올려보고 판정이 어떻게 달라지는지 저장 없이 확인할 수 있습니다
- 키워드는 낱말 하나가 조각(칩)으로 보이고, `×` 로 지우고 입력칸에 쉼표로
  여러 개를 한 번에 넣을 수 있습니다. 새로 넣은 것은 테두리로 표시됩니다
- **중복 검사** — 같은 낱말이 여러 목록에 들어 있는지 보여줍니다.
  일부러 그런 것도 있습니다(`공정가치` 는 `core` 와 `action` 양쪽에 필요)
- **검증 실행** — `점수표_검증.py` 를 편집기 안에서 돌려 결과를 보여줍니다.
  점수표를 고친 뒤 이걸 꼭 눌러보세요
- **되돌리기** — 가장 최근 백업으로 파일을 되돌립니다
- **메일 미리보기** — 저장하기 전에 메일 한 통을 통째로 그려서 보여줍니다
  ([3-2](#3-2-메일-문구-고치기) 참고)
- **실행 탭** — 조회 기간과 옵션을 골라 수집기를 화면에서 돌립니다.
  명령을 칠 필요가 없습니다([2-5](#2-5-시험-삼아-한-번-돌려보기) 참고.
  같은 일을 명령으로 하려면 [부록 A](#부록-a-명령으로-실행하기-선택))

**안전장치**

- **주석이 지워지지 않습니다.** 두 파일은 절반이 주석(설명)입니다. YAML 을
  통째로 다시 쓰면 그게 전부 날아가므로, 편집기는 **고칠 줄만 찾아 그 줄만**
  바꿉니다. 목록 안의 `# --- 기준가격 계열 ---` 같은 구분 주석도 그대로 남습니다
- **쓰기 전에 다시 읽어 확인합니다.** 고친 결과를 YAML 로 다시 파싱해서
  의도한 값과 같은지 대조하고, 다르면 **아예 쓰지 않습니다.** 파일이 반쯤
  망가진 상태로 남는 일이 없습니다
- **저장할 때마다 원본을 `백업/` 폴더에 시각별로 떠둡니다**
- **인증키는 화면에 그대로 보입니다.** 지금 들어 있는 키가 맞는지 눈으로
  확인할 수 있어야 해서입니다. 요금이 붙지 않는 무료 API 이고, 어차피
  `config.yaml` 에 평문으로 들어 있고 이 화면은 이 PC 에서만 열립니다.
  화면을 공유하거나 캡처할 때만 조심하면 됩니다
- SMTP 비밀번호는 사내 메일 계정이라 `••••••••` 로 가려집니다. 그대로 두면
  건드리지 않고, 고치려면 그 칸을 지우고 새로 넣으세요
- 줄바꿈도 파일별로 유지합니다 (`config.yaml` 은 LF, `점수표.yaml` 은 CRLF)

**인증키 칸을 비운 채로 저장하면 키가 지워집니다.** 그 상태로 수집기를 돌리면
`config.yaml 의 service_key 가 비어 있습니다` 로 멈춥니다. 되돌리기 버튼이나
`백업/` 폴더에서 복구하면 됩니다.

**주의**

- 편집기를 열어둔 채로 메모장에서 같은 파일을 고치면 나중에 저장한 쪽이
  이깁니다. 한쪽만 쓰세요
- 검증 실행과 실행 탭은 **저장된 파일**을 읽습니다. 그래서 고친 내용이 남아
  있으면 먼저 저장하라고 알려줍니다
- 실행 탭에서 돌린 수집기는 **편집기 창(검은 창)을 닫으면 같이 멈춥니다.**
  자동 수집은 편집기와 상관없이 작업 스케줄러가 `실행.bat` 으로 돌립니다
  ([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러))

### 3-1. 메일 켜기·끄기, 메일만 보내기

```yaml
mail:
  enabled: true
  mode: outlook            # outlook | smtp
  to:
    - '담당자@회사.co.kr'   # 테스트 단계에는 한 명만
  cc: []
  draft_only: false        # true 면 보내지 않고 아웃룩에 초안만 띄움
  attach_excel: true       # 공고목록.xlsx 첨부
  attach_pdf: true         # 표에 오른 공고의 공고문 PDF 첨부
  attach_max_mb: 15        # 첨부 총 용량 상한
  send_when_empty: true    # 신규 0건일 때도 '특이사항 없음' 한 줄 발송
```

수집이 끝나면 **그 회차에 새로 잡힌 공고만** 메일로 나갑니다.
본문 표는 `구분 · 정확도 · 등록일 · 수요기관 · 공고명 · 마감일시 · 검색 키워드`
이고, 공고명을 누르면 나라장터 공고 화면이 열립니다.

- **구분** — 그 메일 안에서의 순번(1, 2, 3…)입니다. 엑셀에는 없습니다.
  엑셀은 실행할 때마다 아래로 쌓이는 파일이라 회차마다 번호가 겹칩니다
- **검색 키워드** — 무엇에 걸려서 올라왔는지만 짧게 보여줍니다.
  A 는 `업종코드 3865` / `채권평가회사`, B·C 는 공고명에서 걸린 낱말
  (`공정가치평가, 대체투자자산`). 점수 계산 내역(`조합+4`)은 넣지 않습니다.
  `공정가치평가` 가 걸리면 `공정가치` `평가` 는 겹치므로 긴 것만 남깁니다

**수집 없이 메일만 다시 보내기**

```
python 수집기.py --메일만
```

`공고목록.xlsx` 에서 **마지막 회차**를 읽어 그 내용으로 메일만 보냅니다.
API 를 호출하지 않으므로 호출 한도를 쓰지 않고, 몇 초면 끝납니다.
메일이 실패해서 다시 보낼 때도 이걸 씁니다.
`mail.enabled` 가 `false` 여도 보냅니다(보내려고 실행한 것이므로).

처음 설정할 때는 아래 순서를 권합니다.

1. `pip install pywin32`
2. `config.yaml` 에서 `to` 를 본인 주소로, `draft_only: true`
3. `python 수집기.py --메일만` → **아웃룩에 초안이 뜹니다.** 내용 확인
4. 문제 없으면 `draft_only: false` 로 바꾸고 다시 실행하면 실제로 발송

**첨부**

`attach_pdf: true` 면 표에 오른 공고의 공고문을 `공고문/` 폴더에서 찾아 붙입니다.
**이번에 새로 받은 것만이 아니라** 표에 오른 건이면 전부 붙으므로,
`--메일만` 으로 다시 보낼 때도 첨부가 빠지지 않습니다.
합계가 `attach_max_mb` 를 넘으면 넘는 지점부터 붙이지 않고 화면에 알려줍니다
(본문 표는 그대로이므로 내용 확인은 됩니다).

**신규 0건일 때**

`send_when_empty: true` 면 이 한 줄만 나갑니다. 표도 첨부도 없습니다.

```
제목  [나라장터] 08.13(오전) 입찰 공고 특이사항 없습니다
본문  08.13(오전) 나라장터 입찰 공고 특이사항 없습니다.
```

`false` 로 두면 아무것도 보내지 않습니다. 다만 그러면 받는 쪽에서
**"공고가 없었다" 와 "수집기가 죽었다" 를 구분할 수 없습니다.**
켜두는 편이 안전합니다.

### 3-2. 메일 문구 고치기

문구는 전부 `config.yaml` 의 `mail.문구` 에 있습니다.
메모장으로 고치고 저장하면 다음 발송부터 반영됩니다.

**`편집기.bat` 의 `config.yaml` 탭에서 고치는 편이 낫습니다.** 문구 항목 아래
**메일 미리보기** 버튼을 누르면 저장하기 전에 메일 한 통이 통째로 나옵니다.

- 실제로 보낼 때 쓰는 코드가 그대로 그립니다. 미리보기와 실제 메일이
  달라지지 않습니다
- **`공고 3건` / `신규 0건` 을 눌러 두 경우를 다 보세요.** 0건 메일은
  `제목_없음` 과 `없음` 만 나가는 완전히 다른 메일이고, 실무에서 가장 자주
  나가는 것이 이쪽입니다
- 예시에는 A·B·C 가 하나씩 들어 있어 회색 줄과 `검토안내` 까지 같이 보입니다
- **자리표시자를 틀리면 타이핑하는 즉시 그 칸 아래에 빨간 글씨로 알려줍니다.**
  아래 표의 '쓸 수 있는 값' 도 칸마다 적혀 있습니다

| 항목 | 어디에 나오는가 | 쓸 수 있는 값 |
|---|---|---|
| `제목` | 공고가 있을 때 메일 제목 | `{날짜}` `{건수}` `{내역}` |
| `제목_없음` | 공고가 0건일 때 제목 | `{날짜}` |
| `첫줄` | 본문 맨 윗줄 | `{시각}` `{기간}` |
| `요약` | 표 바로 위 (굵게) | `{건수}` `{내역}` |
| `없음` | 0건일 때 본문 (이 한 줄이 전부) | `{날짜}` |
| `안내` | 표 아래 회색 글씨 (A·B·C 설명) | — |
| `검토안내` | C 가 있을 때만 덧붙음 | — |
| `꼬리말` | 맨 아래 작은 글씨 | `{폴더}` |

`{중괄호}` 는 보낼 때 값으로 바뀝니다.

```
{날짜}  08.13(오전)
{건수}  13
{내역}  수집 9건 · 검토 4건
{시각}  2026.08.13 09:00
{기간}  조회기간 08.12 21:00 ~ 08.13 09:00
{폴더}  결과가 저장된 경로
```

표 아래 A·B·C 설명은 `안내` 항목입니다. 현재 값은 이렇습니다.

```yaml
    안내: |-
      공고명을 누르면 나라장터 공고 화면이 열립니다.
      A = 시가/대체 평가 및 채권평가회사(업종코드) 키워드 일치 · B = 키워드 일부 일치 · C = 기금/공제회 관련, 검토 필요 공고 (회색 줄)
```

고칠 때 알아둘 것:

- 줄 전체를 **작은따옴표로 감싸세요.** 안에 작은따옴표를 넣으려면 두 번(`''`)
- 여러 줄로 쓰려면 `안내: |-` 처럼 쓰고 아래에 들여쓰기해서 적습니다.
  줄바꿈은 메일에서도 줄바꿈으로 나갑니다
- 항목을 **지우거나 비워두면 기본 문구**가 쓰입니다
- **없는 이름(예: `{날자}`)을 쓰면 그 줄만 기본 문구로 나가고** 화면에
  `[주의] mail.문구.제목 를 쓸 수 없어…` 라고 알려줍니다. 메일 자체가
  안 나가는 일은 없습니다. 다만 **자동 실행 중에는 이 알림이 `로그\실행.log`
  에만 남아** 알아채기 어렵습니다. 그래서 편집기가 고치는 동안 바로 잡아줍니다
- 표의 컬럼 이름과 정확도 표시(`A 일치` 등)는 여기서 못 바꿉니다

### 3-3. 발송 방식 (아웃룩 / SMTP)

| | `mode: outlook` | `mode: smtp` |
|---|---|---|
| 필요한 것 | 이 PC에 설치된 아웃룩, `pip install pywin32` | 사내 메일 서버 주소·포트 (IT 문의) |
| 발신자 | 아웃룩에 로그인한 본인 계정 | `smtp.from` 에 적은 주소 |
| 막힐 수 있는 경우 | 보안 정책으로 스크립트의 아웃룩 사용 차단 | 릴레이 허용 IP·인증 정책 |

**아웃룩 방식이 준비가 간단합니다.** 서버 정보를 받을 필요가 없습니다.
다만 **아웃룩이 실행 중이어야** 하고, 작업 스케줄러로 돌릴 때는
"사용자가 로그온할 때만 실행" 으로 둬야 합니다(로그온 세션이 없으면
아웃룩을 띄울 수 없습니다).

로그온 여부와 무관하게 자동 발송해야 하면 `mode: smtp` 를 써야 하고,
IT 부서에서 아래를 받아야 합니다.

- 사내 SMTP 서버 주소와 포트 (릴레이 25 / 인증 587)
- 인증이 필요한지, 필요하면 발송 전용 계정
- 발신 주소로 쓸 수 있는 계정 (예: `나라장터알림@회사.co.kr`)

### 3-4. 키워드·점수표 고치기

공고명 판정에 쓰는 키워드는 전부 `점수표.yaml` 에 있습니다.

| 항목 | 뜻 | 배점 |
|---|---|---|
| `core` | 평가 확정어 (`공정가치평가` `시가평가` …) | 8점씩, 최대 3개 |
| `market` | 채권시장 제도·연구 (`장외채권` `채권시장` …) | 8점 |
| `target` | 평가 대상 (`대체투자자산` `기금` `펀드` …) | 2점씩, 최대 2개 |
| `action` | 평가·산출 행위 (`평가` `검증` `산출` …) | 2점씩, 최대 2개 |
| `selectee` / `delegate` | 우리가 '뽑히는 쪽'이 아닌 공고를 0점 처리 / 그 예외 | — |
| `kill_hard` | 확정 제외 (`환경영향평가` `회계감사` …) | -12점씩 |
| `kill_soft` | 약한 제외 (`시스템 구축` `유지관리` …) | -5점씩 |
| `inst_bonus` / `inst_extra` | 기관 가점 | +3 / +2 |
| `pdf_strong` | 공고문 PDF 본문에서 찾을 키워드 | — |
| `cut_collect` / `cut_review` / `cut_review_low` | 수집·검토 문턱 (13 / 7 / 5) | — |

`target` 과 `action` 이 둘 다 걸리면 +4 가 붙습니다.

**고친 뒤에는 반드시 검증을 돌리세요.** 편집기에서 **검증 실행** 버튼을 누르면
됩니다. 명령으로 돌리려면 이것과 같습니다.

```
python 점수표_검증.py
```

검증용 공고 8건이 여전히 잡히는지, 걸러야 할 것이 걸러지는지 40개 항목을 확인합니다.
키워드 하나 고쳤다가 다른 공고를 놓치는 사고를 막는 장치입니다.
마지막 4개는 공고문에서 자격요건 구간을 제대로 잘라내는지 보는 항목으로,
`pdf_strong` 을 고쳤을 때 같이 확인됩니다.

**놓친 공고가 발견되면** 그 공고명을 `점수표_검증.py` 의 `필수` 목록에 추가하고,
통과할 때까지 `점수표.yaml` 을 고칩니다. 검증 목록이 회귀 테스트 역할을 합니다.

개별 공고명만 빠르게 확인하려면 **편집기 아래쪽 칸에 공고명을 넣으면** 됩니다.
저장하기 전 상태로 채점하므로, 고친 것이 어떻게 먹히는지 바로 보입니다.
명령으로는 이것과 같습니다.

```
python 점수.py "대체투자자산 공정가치평가 용역" "국민연금공단"
```

실제 공고에 어떻게 먹히는지 보려면 **PDF 없이 목록만** 한 번 돌려보는 것이
빠릅니다. 엑셀의 **점수·근거** 칸에 왜 그 판정이 나왔는지 그대로 찍힙니다.

```
python 수집기.py 30 --목록만 --메일없이
```

### 3-5. 대상 기관 고치기

`config.yaml` 의 `institutions` 에 기관 이름의 **일부만** 적으면 됩니다.
`공제회` 한 줄로 군인공제회·행정공제회·교직원공제회가 모두 걸립니다.
공고기관과 수요기관을 **둘 다** 검사합니다(조달청 대행 공고는 공고기관이
'조달청'이고 실제 발주처가 수요기관에 들어가기 때문입니다).

여기 있으면 버리는 게 아니라 **+3점 가점**입니다. 목록에 없어도 공고명 점수가
높으면 수집됩니다. 그래서 한국벤처투자·전파진흥원처럼 목록에 없던 기금
운용기관 공고도 잡힙니다.

`institutions_low_cut` 에 있는 기관(연기금 4곳 + 공제회)은 검토(C) 문턱이
7점이 아니라 **5점**입니다. 이유는 [4-4](#4-4-연기금공제회-문턱을-낮춘-이유) 를 보세요.

### 3-6. 조회 기간 (hours)

```yaml
hours: 168     # 168 = 7일
```

**넉넉하게 잡는 것이 맞습니다.** 이미 보낸 건은 `_수집이력.json` 이 걸러내므로
겹쳐서 조회해도 메일에는 새 공고만 나옵니다.
평일 2회·주말 휴무 일정이라면 168 을 권합니다
([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러) 참고).

### 3-7. 저장 위치 (네트워크 공유폴더)

결과를 공유폴더에 쌓으면 **다른 사람은 아무것도 설치할 필요가 없습니다.**

```yaml
output_dir: '\\파일서버\공유\조달\공고수집'
```

**작은따옴표를 쓰세요.** 큰따옴표 안에서는 `\` 가 특수문자로 해석돼 경로가 깨집니다.

**드라이브 문자(Z:)를 쓰면 안 됩니다.** 매핑된 드라이브는 **로그인한 세션에만
존재**합니다. 작업 스케줄러를 "사용자의 로그온 여부에 관계없이 실행"으로 두면
그 드라이브를 못 찾아 매일 조용히 실패합니다. 반드시 `\\서버이름\...` 형태로 쓰세요.

**실행은 한 대에서만.** 여러 PC가 같은 공유폴더에 동시에 쓰면 엑셀과 수집 이력이
깨집니다. 실행 중에는 `_실행중.lock` 이 생기고, 다른 PC에서 실행하면 중단됩니다.
비정상 종료로 남았다면 3시간 뒤 자동으로 무시되고, 급하면 직접 지우면 됩니다.

### 3-8. 오전·오후 두 번 보내기

작업 스케줄러에 **트리거를 두 개** 만들고 `hours: 12` 로 두면 됩니다.
직전 12시간 안에 올라온 공고만 보므로 같은 공고가 두 번 가지 않습니다
(`_수집이력.json` 이 한 번 더 걸러줍니다).
제목에 `오전` / `오후` 가 자동으로 붙습니다.

```
[나라장터] 08/13 오전 신규 5건 (수집 3건 · 검토 2건)
```

다만 평일 2회·주말 휴무 일정에서는 `hours: 12` 가 시간대를 비웁니다.
`hours: 168` 을 권하는 이유는 [2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러) 에 있습니다.

### 3-9. YAML 을 직접 고쳐야 할 때

평소에는 `편집기.bat` 만 쓰면 됩니다. 아래 세 경우에만 `config.yaml` ·
`점수표.yaml` 을 메모장으로 직접 엽니다.

- 편집기가 **아예 안 열릴 때** (검은 창에 오류가 뜨고 브라우저가 안 열림)
- 편집기가 **저장을 거부할 때** (아래 설명)
- 편집기 화면에 **없는 항목**을 고쳐야 할 때

**편집기가 저장을 거부했다면 파일은 그대로입니다.** 편집기는 고친 내용을
파일에 쓰기 직전에 다시 읽어보고, 의도한 값과 다르면 **아예 쓰지 않습니다.**
그러니 "저장하지 못했습니다" 가 떴을 때 파일이 반쯤 망가졌을 걱정은 없습니다.
그대로 메모장으로 고치면 됩니다.

| 편집기가 이렇게 말하면 | 뜻 |
|---|---|
| `YAML 로 읽히지 않습니다` | 넣은 값에 YAML 이 특별하게 보는 문자가 있습니다. 그 값을 따옴표로 감싸세요 |
| `의도한 값과 다릅니다` | 편집기가 고칠 줄을 잘못 찾았습니다. 그 항목만 메모장에서 고치세요 |
| `…를 찾지 못했습니다` | 그 항목이 `config.yaml` 에 아예 없습니다. `config.example.yaml` 에서 해당 줄을 복사해 넣으세요 |

**메모장으로 여는 법** — 파일 우클릭 → 연결 프로그램 → 메모장.
**저장할 때 인코딩을 `UTF-8` 로 두세요.** 저장 창 아래쪽에 있습니다.
`ANSI` 로 저장하면 한글이 전부 깨져서 수집기가 읽지 못합니다.

**직접 고칠 때 지킬 것 다섯 가지**

```yaml
hours: 168                  # ① 이름 다음에 콜론, 그 뒤에 공백 한 칸
institutions:
  - 국민연금공단              # ② 목록은 공백 두 칸 + 하이픈 + 공백
  - 공제회
industry_codes:
  - '3865'                  # ③ 숫자처럼 보이는 값은 따옴표로
output_dir: './수집결과'      # ④ 마침표·역슬래시로 시작하는 값도 따옴표로
# 이 줄은 설명입니다          # ⑤ # 뒤는 프로그램이 안 읽습니다
```

1. **`이름: 값`** — 콜론 뒤에 공백이 한 칸 있어야 합니다. `hours:168` 은 안 됩니다
2. **들여쓰기는 공백만.** Tab 키를 쓰면 안 됩니다. 눈으로는 같아 보이는데
   프로그램은 오류를 냅니다. 위아래 줄과 칸 수를 똑같이 맞추세요
3. **`3865` 처럼 숫자만 있는 값은 `'3865'`** 로 감쌉니다. 안 감싸면 숫자로
   읽혀서 업종코드가 안 맞습니다
4. **`:` 나 `#` 가 값 안에 들어가면** 그 값 전체를 따옴표로 감쌉니다
5. 지우고 싶은 줄은 **맨 앞에 `#` 를 붙이면** 지우지 않고 끌 수 있습니다.
   나중에 되살리기 쉽습니다

**고친 뒤 확인** — `편집기.bat` 을 다시 열어보세요. **열리면 문법이 맞은 것**
입니다. 편집기는 두 파일을 읽어야 화면을 그리므로, 문법이 틀리면 검은 창에
몇 번째 줄이 문제인지 나옵니다. 점수표를 고쳤다면 이어서 **검증 실행**까지
누르세요.

**망가뜨렸으면 되돌리면 됩니다**

- `백업/` 폴더에 편집기가 저장할 때마다 떠둔 원본이 시각별로 있습니다.
  가장 최근 것을 복사해 이름을 `config.yaml` 로 바꾸면 끝입니다.
  편집기의 **되돌리기** 버튼이 이걸 대신 해줍니다
- `config.yaml` 을 손쓸 수 없게 됐으면 `config.example.yaml` 을 복사해
  `config.yaml` 로 이름을 바꾸고 [2-4](#2-4-설정-채우기-편집기bat) 를 다시 하세요.
  인증키와 받는 사람만 넣으면 됩니다

## 4. 왜 이렇게 만들었는가

### 4-1. 판정 순서

```
[1차] 면허제한 API 에 업종코드 3865       → 무조건 수집             [A]
[2차] 공고명 점수 (점수표.yaml)
        13점 이상 → 3차로
        7~12점    → 3차로 (검토 필요)
                    연기금·공제회는 5점부터
        그 미만   → 버림
[3차] 위 후보만 첨부 PDF 를 열어 자격요건 확인
[4차] PDF 에 '채권평가회사' '3865' 등 발견 → 무조건 수집             [A]
[5차] PDF 키워드 없지만 13점 이상          → 수집                   [B]
[6차] PDF 키워드 없고 7~12점               → 검토 필요로 표시        [C]
```

**3차에서 PDF 를 여는 대상을 2차 통과분으로 좁힌 이유**는 호출량입니다.
한 달 공고가 약 3만 건이라 전부 PDF 를 열 수는 없습니다.
공고명 점수로 후보를 줄인 다음에만 PDF 를 봅니다.

### 4-2. 정확도 A · B · C

| | 뜻 | 어떻게 걸렸나 |
|---|---|---|
| **A** | 시가/대체 평가 및 채권평가회사(업종코드) 키워드 일치 | 면허제한에 3865 가 있거나, 공고문 자격요건에 '채권평가회사'·'3865' 가 적혀 있음 |
| **B** | 키워드 일부 일치 | 위 키워드는 없지만 공고명 점수가 13점 이상 |
| **C** | 기금/공제회 관련, 검토 필요 공고 | 공단·공제회 등의 평가성 공고인데 점수가 7~12점이라 애매함 |

**A 는 근거가 두 가지(면허제한 / 공고문)지만 결론이 같아 하나로 묶었습니다.**
어느 쪽으로 걸렸는지는 엑셀의 **근거** 칸에서 볼 수 있습니다.

**C 도 같은 엑셀·같은 메일에 들어갑니다.** 애매한 건을 다른 파일로 빼면
그 파일을 안 열어보게 되기 때문입니다. 엑셀에서는 **회색 줄**, 메일에서는
**C 검토** 로 구분됩니다.

**기관만 맞는 공고는 가져오지 않습니다.** '국민연금공단 3급 승진 역량평가'
처럼 기관은 대상이지만 평가 키워드가 없는 건은 점수 미달로 버려집니다.
C 는 기관과 **평가 관련 키워드가 함께** 걸린 것만 들어옵니다.

### 4-3. 살아있는 공고만 남기는 이유

판정에 앞서 **살아있는 공고만 남깁니다.** 목록 API 는 같은 공고를 차수마다
한 줄씩 주는데, 나라장터 화면은 최신 차수만 보여줍니다. 그대로 두면 한 공고가
엑셀에 여러 줄로 쌓입니다.

- 같은 공고번호는 **차수가 가장 높은 것 하나만** 씁니다
- **취소공고는 그 공고번호를 통째로 버립니다.** 취소 줄만 빼면 이미 없어진
  원공고가 마감일시를 달고 남아 살아있는 것처럼 보입니다.
  공고를 취소하고 몇 분 뒤 **새 번호로 다시 올리는** 기관이 실제로 있습니다
  (국민연금공단 대체투자자산 건이 그랬습니다)

### 4-4. 연기금·공제회 문턱을 낮춘 이유

`config.yaml` 의 `institutions_low_cut` 에 있는 기관(연기금 4곳 + 공제회)은
검토 문턱이 7점이 아니라 **5점**입니다. 이 기관들은 확정어 없이 5~6점에
머무는 공고가 실제로 우리 일인 경우가 있습니다.

```
5점  한국지방재정공제회  자산운용 컨설팅 연구용역          → C 로 올라옴
6점  건설근로자공제회    기준 포트폴리오 도입 및 중장기 자산운용전략 개편 연구용역
5점  국민연금공단        ESG 평가데이터 및 ESG 이슈 리서치 제공기관 선정
```

4개월 기준 **13건(월 3건)** 늘어납니다.

**금융공공기관까지 넓히지 마세요.** 같은 4개월에서 13건이 **77건**이 되고,
늘어난 대부분이 뉴스 모니터링·노후장비 교체·감정평가법인 선정처럼 무관한
공고입니다. `기술보증기금 탄소가치평가모델 고도화`(5점)처럼 **걸러야 하는
공고까지 올라옵니다.** 배점은 `점수표.yaml` 의 `cut_review_low` 입니다.

### 4-5. 한 가지 방법만으로는 안 되는 이유

**PDF 키워드만 믿으면 안 됩니다.** 검증용 공고 8건 중 2건
(한국예탁결제원 장외 채권거래, 한국산업은행 모펀드 성과평가)은
공고문에 '채권평가회사'·'3865' 가 아예 없습니다. 그래서 공고명 점수가 따로 있습니다.

**공고명 점수만 믿어도 안 됩니다.** 그래서 1차 면허제한 조회가 따로 있습니다.

**면허제한 API 만 믿어도 안 됩니다.** 허용업종을 아무것도 적지 않는 공고가
많습니다. 그래서 공고문 PDF 를 열어보는 3·4차가 있습니다.

세 가지가 서로를 메우는 구조입니다. 하나를 빼면 그만큼 놓칩니다.

### 4-6. 엑셀 컬럼과 PDF 파일명

**엑셀 컬럼**

| 정확도 | 등록일 | 수요기관 | 공고기관 | 공고명 | 마감일시 | 업무 | 점수 | 키워드 | 근거 | 첨부 | 공고번호 | 링크 | 수집일시 |

- **정확도** — A·B 는 수집분, **C 는 검토 필요분**이고 **행 전체가 회색**입니다.
  이 칸에 자동 필터가 걸려 있어 C만 골라 보거나 빼고 볼 수 있습니다
- **점수** — 공고명 기반 점수. 메일에는 안 나오고 엑셀에만 있습니다.
  점수표를 다듬을 때 쓰는 값입니다
- **키워드** — `업종코드 3865` / `채권평가회사` / `3864` / `-`
- **근거** — 왜 그 판정이 나왔는지 그대로 보여줍니다. 점수표를 고칠 때 이걸 보세요
  - B·C: `확정: 공정가치평가 · 대상: 대체투자자산 · 조합+4 · 기관+3`
  - A(면허제한): `면허제한(3개 허용): 채권평가회사/3865, 회계법인/1200, 종합금융투자사업자/7096`
    허용업종을 **전부** 적되 우리가 걸린 업종을 맨 앞에 놓습니다.
    허용업종이 여러 개면 회계법인·신용평가사 등과 경쟁하는 공고라는 뜻입니다.
    **메일에는 이 뒷부분이 안 나옵니다.** 훑어볼 때는 군더더기라서,
    경쟁 구도를 볼 때만 엑셀에서 확인합니다
- **첨부** — 그 공고에 달린 첨부파일 개수 (받는 건 공고문 PDF 하나뿐입니다)
- **수집일시** — 이 줄을 만든 실행 시각. 한 번 실행분은 전부 같은 값이라
  **"어제 배치에서 새로 올라온 것만"** 을 필터로 골라볼 수 있습니다

**공고문 PDF**

엑셀에 오른 건만, **한 건당 한 개**만 받습니다. 파일명은
`기관_공고명_공고번호.pdf` 입니다.

- 기관은 **수요기관**을 씁니다. 조달청 대행 공고는 공고기관이 전부 '조달청' 이라
  파일명으로 구분이 안 되기 때문입니다. 수요기관이 비어 있으면 공고기관을 씁니다
- 공고번호를 붙이는 이유는 같은 기관이 같은 이름으로 재공고하는 일이 흔해서입니다.
  안 붙이면 앞 건을 덮어씁니다
- 첨부가 여러 개면 **자격요건 키워드가 나온 문서**를, 아무 데서도 안 나왔으면
  **첫 번째 PDF**(보통 입찰공고문)를 남깁니다
- HWP·ZIP 등 나머지 첨부는 받지 않습니다. 필요하면 엑셀의 **링크** 칸에서
  나라장터 공고 화면을 열면 됩니다

### 4-7. 알아두면 좋은 것

**"마감일시" 는 입찰서 제출 마감일시(`bidClseDt`)입니다.** 협상에 의한 계약에서는
대개 제안서 마감과 같지만 별도로 정해진 경우가 있습니다.
실제 제출 전에는 공고문 원문을 반드시 확인하세요.

**`2026-08-21 09:00 (개찰)` 처럼 뒤에 (개찰) 이 붙은 것**은 마감일시가 아니라
개찰일시입니다. 직찰·우편 방식 공고는 전자입찰 마감시각이 아예 없어서
나라장터 화면에서도 입찰마감일시가 공란입니다. 빈칸으로 두면 놓치기 쉬워
개찰일시를 대신 넣되 표시해 둡니다. **이 경우 제출 마감은 공고문에서
반드시 확인해야 합니다.** 용역 공고의 14% 정도가 여기 해당합니다.

**PDF 검사는 PDF 첨부만 봅니다.** HWP 는 읽지 못합니다.
자격요건이 HWP 제안요청서에만 있으면 4차에서 못 잡습니다.
이것도 공고명 점수와 1차 면허제한이 따로 있는 이유입니다.
스캔본이라 본문 텍스트가 아예 없는 공고문도 같은 이유로 못 읽습니다.

**엑셀을 열어둔 채로 실행하면 저장이 안 됩니다.** 공고문 PDF 는 정상적으로
받아지지만 엑셀 기록이 빠지니, 자동 실행 시간대에는 닫아두세요.
메일 본문은 그대로 나갑니다(내용은 메모리에서 만듭니다). 다만 **첨부된 엑셀은
이번 회차가 빠진 이전 파일**이니, 그럴 때는 본문 표를 보세요.

**`_수집이력.json` 을 지우면** 그동안 받은 공고를 처음부터 다시 받습니다.
점수표를 크게 고친 뒤 다시 판정하고 싶을 때 씁니다.

**엑셀 컬럼 구성이 바뀌면** 기존 파일을 `공고목록_이전_날짜.xlsx` 로 옮겨두고
새로 시작합니다. 값이 한 칸씩 밀린 채 쌓이는 것을 막기 위한 것으로,
옮겨둔 파일은 그대로 열어볼 수 있습니다.

| 편집기가 `저장하지 못했습니다` | **파일은 그대로입니다.** 그 항목만 메모장으로 고치세요 ([3-9](#3-9-yaml-을-직접-고쳐야-할-때)) |
| 설정을 고쳤는데 수집 결과가 그대로 | 편집기에서 **저장**을 눌렀는지 확인. 고친 것은 다음 실행부터 반영됩니다 |
| 메모장으로 고친 뒤 한글이 깨짐 | `ANSI` 로 저장한 것입니다. `백업/` 에서 되돌리고 인코딩을 `UTF-8` 로 다시 저장 |
| 면허제한 조회가 자꾸 끊김 | 기간을 7일씩 나눠 실행. 캐시가 남아 이어집니다 |
| `pip: 명령을 찾을 수 없음` | 파이썬 설치 시 PATH 체크 누락. 재설치 |
| 메일이 안 감 (`mail.to 가 비어 있어`) | `config.yaml` 의 `mail.to` 에 주소를 넣고 `enabled: true` |
| `아웃룩 발송에는 pywin32 가 필요` | `pip install pywin32` |
| `아웃룩 발송 —` 오류 | 아웃룩을 먼저 실행. 그래도 안 되면 보안 정책 문제이므로 `mode: smtp` |
| `mail.smtp 의 host / from 이 비어` | 사내 SMTP 정보를 IT 에서 받아 채우기 |
| 자동 실행이 안 돎 | **`로그\실행.log` 에 그 시각 헤더가 있는지부터 확인.** 없으면 파이썬이 시작조차 못 한 것이므로 바로 아래 항목들을, 있으면 작업 스케줄러의 "사용자가 로그온할 때만 실행" · 배터리 설정을 보세요 |
| `'thon'은(는) 내부 또는 외부 명령…` / 한글 한 줄이 명령으로 실행됨 | `실행.bat` 이 UTF-8 로 저장됨. **CP949(ANSI) + CRLF** 로 저장하고 `chcp` 줄을 넣지 마세요 ([2-6](#2-6-실행bat-준비하기)) |
| `로그\실행.log` 가 안 생기거나 0바이트 | 배치가 같은 파일을 리다이렉트(`>>`)로 잡고 있으면 cmd 가 파일을 잠가 파이썬이 못 씁니다. 오류 출력은 `로그\오류.log` 로 분리 |
| 스케줄러 작업이 계속 "실행 중" | 오류 후 `pause` 에서 멈춘 것. `/tr` 의 경로 뒤에 `auto` 인자가 붙었는지 확인 ([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러)) |
| 오류 창이 떴는데 스케줄러 기록은 `0`(성공) | `실행.bat` 맨 끝에 `exit /b %RC%` 가 있는지 확인 |
| 공유폴더에 저장이 안 됨 | `Z:` 같은 드라이브 문자 대신 `\\서버이름\...` 으로 |

## 부록 A. 명령으로 실행하기 (선택)

**여기는 안 봐도 됩니다.** [2](#2-실행-방법) 대로 설치했으면 자동 실행은
작업 스케줄러가, 손으로 돌리는 것은 `편집기.bat` 의 **실행** 탭이 합니다.
명령 프롬프트에 익숙한 사람이 같은 일을 더 빨리 하고 싶을 때만 쓰세요.

```
python 수집기.py              config.yaml 의 hours 만큼 (매일 자동실행용)
python 수집기.py 30           최근 30일
python 수집기.py 30 --목록만   PDF 저장 없이 엑셀만 (점수표 다듬을 때)
python 수집기.py --pdf없이     PDF 검사 생략 (빠름, 1·2차만)
python 수집기.py --메일없이    메일 발송만 건너뛴다
python 수집기.py --메일만      수집 없이 엑셀의 마지막 회차를 메일로 (발송 시험용)
```

지난 회차를 재현해 볼 수도 있습니다. 그날 그 시각에 돌렸다면 어떤 메일이
나갔을지 확인할 때 씁니다.

```
python 수집기.py 0.75 --기준 "2026-08-06 10:00" --저장 ./재현확인
```

편집기의 **실행** 탭 화면과 명령은 이렇게 짝지어집니다.

| 화면 | 같은 명령 |
|---|---|
| 조회 범위 `config 의 hours 그대로` | `python 수집기.py` |
| 조회 범위 `최근 30일` | `python 수집기.py 30` |
| 조회 범위 `기준시각 …부터 거슬러 0.75일` | `python 수집기.py 0.75 --기준 "…"` |
| 옵션 `PDF 저장 안 함` | `--목록만` |
| 옵션 `PDF 검사 생략` | `--pdf없이` |
| 옵션 `메일 보내지 않음` (기본 켜짐) | `--메일없이` |
| `저장 폴더` 칸 | `--저장 …` |
| `마지막 회차 메일만 보내기` 버튼 | `--메일만` |

**그래도 화면으로 하는 편이 안전합니다.** 두 가지가 다릅니다.

- **메일이 실제로 나가는 실행인지 실행 전에 알려줍니다.** 받는 사람까지
  빨간 줄로 보여주므로, 시험 삼아 돌렸다가 팀 전체에 메일이 나가는 일이 없습니다
- **기준시각을 넣으면 저장 폴더를 `./재현_20260806_1000` 으로 자동으로 채웁니다.**
  명령줄에서 `--저장` 을 빠뜨리면 재현 결과가 진짜 `_수집이력.json` 과
  `공고목록.xlsx` 에 섞여 들어갑니다

점수표를 다듬을 때 쓰는 명령은 [3-4](#3-4-키워드점수표-고치기) 에 있습니다.

## 부록 B. 실행.bat 안쪽

**여기도 안 봐도 됩니다.** [2-6](#2-6-실행bat-준비하기) 대로 파이썬 경로만
맞춰두면 됩니다. 배치 파일을 고쳐야 할 일이 생겼을 때만 보세요.

```bat
@echo off
setlocal
cd /d "%~dp0"

set PYTHONUTF8=1

set "PY=C:\Users\user\AppData\Local\Python\pythoncore-3.14-64\python.exe"
if not exist "%PY%" set "PY=python"

if not exist "로그" md "로그"

"%PY%" "수집기.py" 2> "로그\오류.log"

set RC=%ERRORLEVEL%

if not "%RC%"=="0" (
    echo.
    echo ============================================
    echo  오류가 발생했습니다. 종료코드 %RC%
    echo  자세한 내용은 로그\실행.log 를 확인하세요.
    echo ============================================
    if /i not "%~1"=="auto" pause
)

exit /b %RC%
```

실제 파일에는 `rem` 주석 줄이 더 붙어 있습니다.
**저장할 때는 CP949(ANSI) + CRLF** 를 지켜야 합니다
([2-6](#2-6-실행bat-준비하기) 참고).

각 줄이 왜 이렇게 되어 있는지:

- **`set "PY=..."`** — `python` 대신 전체 경로를 씁니다. PATH 의 `python` 은
  마이크로소프트 스토어 별칭일 수 있어 작업 스케줄러 환경에서 불안정합니다.
  경로가 없으면 그냥 `python` 으로 돌아갑니다.
  **다른 PC로 옮기면 이 경로를 그 PC의 것으로 고쳐야 합니다** (`where python` 으로 확인)
- **`2> "로그\오류.log"`** — 파이썬이 **아예 못 뜨는** 경우(패키지 누락 등)를 잡습니다.
  정상이면 0바이트 빈 파일입니다. 실행 기록 자체는 수집기가
  `로그\실행.log` 에 직접 남깁니다([2-8](#2-8-만들어지는-것) 참고).
  **두 파일을 하나로 합치면 안 됩니다.** cmd 가 리다이렉트로 파일을 잠근 사이
  파이썬이 같은 파일을 열지 못해 실행 기록이 통째로 빕니다
- **`auto` 인자** — 작업 스케줄러가 붙여줍니다([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러)).
  오류가 나도 `pause` 에서 멈추지 않게 해서, 아무도 없는 시간에 창이 떠 있는 채로
  다음 실행이 막히는 것을 막습니다. 사람이 더블클릭할 때는 인자가 없으므로
  오류 메시지를 읽을 수 있게 멈춥니다
- **`exit /b %RC%`** — 실제 종료 코드를 작업 스케줄러에 넘깁니다. 이게 없으면
  실패해도 스케줄러 기록에 **"마지막 실행 결과: 0(성공)"** 으로 남아 실패를
  알아챌 수 없습니다

검은 창이 거슬리면 `%PY%` 를 `pythonw.exe` 로 바꿀 수 있습니다. 화면 출력은
사라지지만 `로그\실행.log` 는 그대로 남습니다(파이썬은 출력 대상이 없으면
화면 출력만 조용히 건너뜁니다). 다만 오류를 바로 눈치채기 어렵습니다.

**exe 배포판의 `실행.bat` 은 `set "PY=..."` 두 줄이 없습니다.** 대신
`"%~dp0나라장터수집기.exe" 수집` 을 부릅니다. 나머지 줄은 똑같습니다.
그래서 다른 PC 로 옮겨도 고칠 것이 없습니다.

## 부록 C. exe 로 묶어 배포하기

**이 부록은 프로그램을 넘겨주는 쪽이 읽습니다.** 받는 쪽은
[2-0](#2-0-exe-배포판을-받았다면) 만 보면 됩니다.

담당자 PC 에 파이썬을 깔기 어렵거나, 깔더라도 `pip install` 과
`실행.bat` 의 파이썬 경로 수정까지 시키기 어려울 때 씁니다. PyInstaller 로
파이썬과 패키지를 폴더 하나에 담아 넘깁니다.

### C-1. 만들기

소스가 있는 PC 에서 **`빌드.bat` 을 더블클릭**하면 끝입니다.
처음에는 1~2분 걸립니다.

```
dist\나라장터 수집기\      ← 이 폴더를 통째로 복사해서 넘깁니다
```

`빌드.bat` 이 하는 일은 세 가지입니다.

1. `pyinstaller` 와 패키지를 설치·갱신
2. `나라장터수집기.spec` 대로 exe 를 묶음
3. `배포\실행.bat` 과 `README.pdf` 를 배포 폴더에 넣음

명령으로 하려면 이렇게도 됩니다.

```
pip install pyinstaller
pyinstaller 나라장터수집기.spec --noconfirm
```

### C-2. exe 하나에 역할 셋

실행 파일은 하나뿐이고 **첫 인자로 역할을 나눕니다.**

| 명령 | 하는 일 | 누가 부르나 |
|---|---|---|
| `나라장터수집기.exe` | 설정 편집기를 브라우저에 엶 | 담당자가 더블클릭 |
| `나라장터수집기.exe 수집` | 공고 수집 | `실행.bat` → 작업 스케줄러 |
| `나라장터수집기.exe 점수표검증` | 점수표 회귀 검사 | 편집기의 검증 버튼 |

exe 를 여러 개 만들어 서로 찾게 하면 경로가 어긋날 때마다 깨집니다.
하나로 두면 편집기가 수집기를 띄울 때도 `sys.executable`(= 자기 자신)을
그대로 쓰면 되므로 찾을 일이 없습니다.

### C-3. 작업 스케줄러는 그대로 둡니다

스케줄러에 등록된 것은 `실행.bat` 의 **경로**뿐입니다
([2-7](#2-7-윈도우-자동-실행-설정-작업-스케줄러)). 배포판의 `실행.bat` 은
파일 이름과 인자(`auto`)를 그대로 유지한 채 안에서 exe 를 부르므로,
**같은 폴더에 덮어쓴다면 스케줄러는 손댈 필요가 없습니다.**

다만 **폴더 경로가 바뀌면 다시 등록해야 합니다.** `/tr` 에 절대경로가
박혀 있기 때문입니다.

### C-4. 설정 파일을 번들에 넣지 않는 이유

`config.yaml` 과 `점수표.yaml` 은 담당자가 편집기로 고치는 파일입니다.
exe 안에 넣으면 다시 묶기 전까지 못 고칩니다. 그래서 번들에는
**기본값만** 넣어 두고, 첫 실행 때 exe 옆으로 한 번 꺼냅니다
(`앱경로.py` 의 `seed()`). 이미 있으면 손대지 않으므로 새 버전을 덮어써도
고쳐 둔 설정이 남습니다.

인증키가 든 실제 `config.yaml` 은 번들에 들어가지 않습니다.
꺼내지는 것은 `config.example.yaml` 이고 인증키 칸은 비어 있습니다.
이미 쓰던 `config.yaml` 이 있다면 exe 옆에 같이 넣어 주면 됩니다.

### C-5. 걸릴 만한 것

| 증상 | 원인 / 대처 |
|---|---|
| 백신이 exe 를 지우거나 격리 | 서명 없는 PyInstaller exe 는 오탐이 잦습니다. 사내 IT 에 예외 등록을 요청하세요. 막히면 임베디드 파이썬 배포로 돌려야 합니다 |
| `_internal` 을 지웠다 | 실행되지 않습니다. 폴더를 다시 받으세요 |
| 설정을 저장했는데 반영이 안 됨 | `_internal` 안의 `config.yaml` 을 고친 경우입니다. exe **옆**의 것을 고쳐야 합니다 |
| 빌드는 됐는데 실행 시 `ModuleNotFoundError` | 새로 쓴 패키지를 `나라장터수집기.spec` 의 `hiddenimports` 에 넣으세요 |
| 배포 폴더가 너무 큼 | 27MB 정도가 정상입니다. `spec` 의 `excludes` 에 안 쓰는 패키지를 더 넣으면 줄어듭니다 |

`upx` 압축은 일부러 껐습니다. 용량은 줄지만 백신 오탐이 눈에 띄게 늘어납니다.
`onefile` 도 쓰지 않습니다. 실행할 때마다 임시 폴더에 수십 MB 를 풀어야 해서
시작이 느리고, 역시 백신이 더 자주 잡습니다.
