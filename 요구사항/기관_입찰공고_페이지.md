# 공제회·연기금·공공기관 입찰공고 페이지 목록

`0.전략사업실 업무 분장_2026.08.xlsx` 의 **주요금융기관** 시트 중
`연기금/여신/벤더` 블록에서 공제회·연기금·공공기관·공제성 기관만 추린 목록이다.
캐피탈·카드·신탁·정보벤더(더벨·블룸버그·연합인포맥스 등)는 뺐다.

각 기관 홈페이지에 직접 접속해 입찰공고가 실제로 올라오는 게시판 주소를 확인했고,
그다음 **30개 기관 / 게시판 32개를 브라우저로 전수 확인**했다.
확인 방법은 문서 맨 아래에 적어 두었다.

- **확인** ✅ = 게시판을 열어 실제 공고 목록이 보이는 것까지 확인 (게시판 29개)
- **확인** ❌ = 게시판이 비어 있거나 사이트가 열리지 않아 쓸 수 없다 (3개)
- **config** = `config.yaml` 의 `institutions` 등록 여부 (◎ = `institutions_low_cut` 에도 등록)

## 확인 방법

1. 업무분장표의 `연기금/여신/벤더` 블록(9~12열)에서 공제회·연기금·공공기관·공제성 기관만 추렸다.
2. 각 기관 대표 도메인에 HTTP 요청을 보내 응답을 받고, 메뉴·사이트맵의 링크에서
   `입찰`·`공고`·`조달`·`계약` 이 들어간 항목을 뽑았다.
3. 자바스크립트로 메뉴를 그리는 사이트는 웹 검색으로 게시판 주소를 찾은 뒤
   그 주소를 직접 열어 `<title>` 과 본문에 실제 공고 목록이 있는지 확인했다.
4. 한국예탁결제원처럼 React 로 만든 사이트는 자바스크립트 번들에서 라우트 문자열을 찾아냈다.
5. 마지막으로 게시판 32개를 브라우저로 하나씩 열어 눈으로 확인했다.

### 한계

- 처음 정리할 때는 자바스크립트로 목록을 그리는 사이트 4곳을 '본문 확인 못 함' 으로
  남겨 뒀다. 이후 브라우저로 전수 확인해서 **아래를 바로잡았다.**
    - 한국주택금융공사: 자체 게시판은 결과만 올라온다. 공고는 ALIO
    - 한국거래소: 게시판은 있지만 올라온 공고가 없다
    - 우정사업조달센터: 입찰공고 게시판이 비어 있다
    - 산림조합중앙회: 사내 PC 에서도 사이트가 로딩되지 않는다
    - 군인공제회·새마을금고복지회: 못 찾았던 주소를 확보했다.
      군인공제회는 별도 입찰 게시판이 없고 공지사항에 섞이며,
      새마을금고복지회는 입찰공고 전용 게시판이 따로 있다
- 게시판 주소는 홈페이지 개편 때 통째로 바뀐다. 건설근로자공제회는 이미 도메인이
  `cwma.or.kr` → `cw.or.kr` 로 옮겨졌다(구 주소는 리다이렉트된다).
- 매각·임대 공고는 대부분 **온비드(onbid.co.kr)** 소관이라 이 목록의 게시판에도,
  나라장터에도 안 올라온다. 우리 업무와 무관하므로 신경 쓰지 않아도 된다.
- 이 목록은 '자체 사이트' 채널만 정리한 것이다. 대부분의 공고는 여전히
  **나라장터(g2b.go.kr)** 에 올라오고 수집기가 이미 잡고 있다.
  자체 사이트는 나라장터에 안 올라오는 건을 메우는 용도다.
